每个历史窗口从人民币 100,000 元现金起步。四组股债组合保持原定权重，境内六策略沿用冻结协议，均取基准费用、一个交易日执行延迟。账户按每日收盘价估值，计入已核实的分红、模拟交易费用与滑点。不同起点独立建账。此回放仅使用历史快照，截止 2026-10-30。

在 2018-09-14 至 2026-10-30 的 1,967 个交易日，沪深300／国债各半账户期末为 137,767.98 元，年化 4.02%，最大回撤 19.73%，从前高到收复共 1,102 个交易日。最近一年同一配置发生亏损。历史收益依赖区间，长期目标仍需前瞻观察。场内跨境 ETF 的收益含汇率和折溢价影响。模型成交与实际可成交价格仍有差异。

## 复现

在项目目录使用已锁定的 Python 依赖。输出使用新的临时目录：

```sh
out=$(mktemp -d)
python scripts/compare_three_markets.py --output "$out/markets"
python scripts/verify_three_markets.py "$out/markets"
for f in daily.csv orders.csv accounts.csv rolling.csv holdings.json; do
  cmp "$out/markets/$f" "reports/2026-11-08-three-markets/$f" || exit 1
done
python scripts/build_backtest_view.py --output "$out/backtest-data.json"
cmp "$out/backtest-data.json" site/backtest-data.json
```

四组组合的三个窗口合计 5,828 条逐日账户记录、429 条订单记录和 2,916 个滚动窗口。独立脚本核对份额、费用、现金、分红、收盘总资产及回撤恢复。境内六策略另有 11,802 条记录。看板生成器从已核验的快照运行模型，逐日对照原账本的日期、现金、可用现金、应收、各 ETF 份额和总资产，全部相符后导出图表。归档的逐日账本见[四组市场组合](../2026-11-08-three-markets/)和[境内长历史](../2026-11-05-long-history/)。
