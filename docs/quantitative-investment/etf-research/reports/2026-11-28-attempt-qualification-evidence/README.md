# 采集尝试的定时时点和来源缺口

工作台「政策与市场研究」的交易日详情为每份归档显示定时时点证据与缺证来源。手工复查、没有 systemd 管理器时钟、已有时钟但与计划或启动时间不符，以及时点已通过核验，均有独立含义。计划时点以归档记录的原日历和实际启动核验，有记录但未获认可的触发时刻单列。没有形成可核验覆盖结果时，缺证来源保持未知。正式资格继续读归档回执中的原有判定。
