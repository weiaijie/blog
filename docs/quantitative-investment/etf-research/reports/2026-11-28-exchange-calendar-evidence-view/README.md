# 工作台与 Agent 的跨年日历证据

在工作台「政策与市场研究」展开「年度交易日历」，可以查到最近的定时归档与手工复核、两家交易所的收报时间和候选链接。正式准入单列，读取已核验的年度登记和实际生效时点。两家原文齐备只形成候选。定时回执绑定内容归档中的调用身份，回执与原件不符会标记核验失败。

Agent 使用 `GET /api/v1/research/observation/calendar-watch?year=2027`，可附带 `asOf` 查询历史时点。手工检查在核验完成时出现，定时检查在内容归档核验完成时出现，正式年度只从实际登记时点开始准入。
