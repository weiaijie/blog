# Backtrader 固定样例初评（2026-11-06）

结论：**暂不替换冻结模拟引擎**。Backtrader 1.9.78.123 的默认撮合与本协议不同；仅对一个买入场景加定制费用和固定一跳滑点后结果一致，还不能推断完整策略等价。本次均为合成数据，不是历史收益或前瞻成交。

## 可复现样例

使用 Python 3.12.16；仅对照工具额外安装 `backtrader==1.9.78.123`，不改变项目已有锁定依赖。所用 PyPI wheel `backtrader-1.9.78.123-py2.py3-none-any.whl` SHA256 为 `9a07a516b0de9155539a35c56e9404d8711dd7020b3d37b30495e83e1b9d5dfd`。合成数据与订单在 [脚本](../../scripts/compare_backtrader.py) 内，逐日输出见 [comparison.json](comparison.json)。日期为合成标签，并非真实市场数据。

```sh
python -m pip install backtrader==1.9.78.123
python scripts/compare_backtrader.py > comparison.json
```

脚本包含断言，检查观察到的差异和有限适配结果。默认实例采用万3佣金、5bp滑点，旧账本同时采用5元最低佣金、0.001元向不利方向取整；故默认价格与费用差异是**口径不同的预期结果**，不是相同口径下的算法错误。

| 项目 | 实际样例结果 | 范围和含义 |
|---|---|---|
| 时点 | 第一天信号，Backtrader 第二天开盘成交；账本要求此前交易日信号 | 仅覆盖简单市价订单；未验证延迟2/3日和月度目标调仓 |
| 价格及费用 | 默认价1.0005、佣金0.030015、现金899.919985；账本价1.001、佣金5、现金894.9 | 后者含向不利方向一跳、最低佣金及分币规则；Backtrader 默认没有相同设置 |
| 限定适配 | 针对本样例设一跳固定滑点及定制最低佣金，成交价1.001、佣金5、现金894.9一致 | 仅一只ETF一次买入；固定一跳不等于通用bps及刻度计算，不证明其他订单等价 |
| 整手 | Backtrader 默认成交101份；账本拒绝 | 接入前必须约束所有订单，而不是只依赖默认下单 |
| 现金不足 | 100元初始现金买100份：Backtrader 为 Margin，账本拒绝 | 费用各自按各自口径计算；不能证明所有现金边界一致 |
| 无持仓卖出 | Backtrader 默认持仓变为-100；账本拒绝 | 必须显式禁止卖空 |
| 分红 | 账本登记日锁定100份；除息日应收10元；发放日现金10元但可用0；次交易日可用10元 | 本轮**没有**Backtrader 分红事件适配与对照；不能称分红等价 |
| 当日回卖 | 账本合成检查 T+0 成交、T+1 拒绝 | 日线样例没有完成 Backtrader 同日多订单时序对照，不能称已支持交易制度 |

Backtrader 文档的[滑点说明](https://www.backtrader.com/docu/slippage/slippage/)还说明默认可能以日高低价限制滑点；项目现有结果中有模型成交价超日内范围的情形，适配不能静默沿用不同约束。[Broker 文档](https://www.backtrader.com/docu/broker/)提供现金、佣金和滑点扩展接口，但接口存在不等于自动符合本协议。

## 决策与剩余验证

保留现有协议、旧引擎和报告；目前仅考虑将 Backtrader 作为隔离的独立执行对照候选。下一步设计单独适配层和逐日双账本比较：登记/除息/支付（含非交易日）与发放日不可用、T+0/T+1、整手、卖空、分币及不利刻度、卖税、同日先卖后买、现金边界、1/2/3日延迟、除息日禁交易、9%缓冲及缺失/停牌拒绝；再用固定历史前缀与全部162场景核验订单、拒绝、现金、应收、持仓和净值，不只比较最终收益。适配不通过则不迁移。历史数据、未解决正式参考价和停复牌证据限制不因引入框架改变。
