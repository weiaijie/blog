# 独立研究的训练和预测封存

模型定时器在北京时间 07:45 检查预登记折。折首日 00:00 为训练截止，逐日核验合格决策、五交易日标签、实际可用时点及归档标识。跨折持有窗口、截止时才就绪或晚于截止的标签均排除，保留日期与原因。同一增量比较的基线及扩展模型使用相同的日期和目标，满 40 行才拟合。归档包含训练矩阵、费用口径对应的标签、用于防止事件跨段复用的事件 ID、模型参数和哈希。

预测定时器在 08:53 运行，短时等待 08:52 的决策输入封存。逐项读取已通过核验的模型与当日输入，按固定模型计算成对的五日收益及最大回撤预测。跨折窗口、缺输入、训练行不足和政策事件重复各有状态。只有 08:55 前已实际归档核验的预测进入后续评价，迟到时记录实际时间和原因。预测核验可从对应模型、决策归档和当日特征复算，持有期结果由独立标签程序随后完成。

## 验收证据

- [真实运行状态](status-probe.json)读取了 Ubuntu 的独立生产归档，首个合格归档仍为空，现场暂无可拟合模型和正式预测。
- 隔离试验合成 42 个已知时点训练决策，验证政策比较 40 行、ETF 比较 42 行能够拟合，两融和全量比较各 39 行均保存样本不足。额外改动只存在于 ETF 比较的目标值，政策比较的模型哈希保持一致。
- 在同一隔离环境完成模型归档恢复、当日决策封存、预测实际时钟核验及重放。ETF 比较产出预测，政策比较因遇到训练期已有事件被排除。跨折、晚于截止、仅计算完成而归档迟到和内容损坏情形均经过测试。

在锁定的 Python 环境可复现隔离验收。

```bash
PYTHONPATH=src python -m unittest discover -s tests -p 'test_train_observation_models.py' -v
PYTHONPATH=src python -m unittest discover -s tests -p 'test_seal_observation_forecasts.py' -v
```

自动运行后持续核对例行日志。正式样本外比较仍须满足预登记的 120 个不同决策日、至少两个样本外季度及政策独立事件门槛。
