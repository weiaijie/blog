# 训练与预测覆盖看板

工作台「政策与市场研究」和 Agent 共用 `/api/v1/research/observation`。总览新增 `modelProgress` 与 `forecastCounts`。按交易日查询 `?day=YYYY-MM-DD` 返回当日预测封存、截止前可用的模型、每项比较的状态和校验值。

- 应预测日采用独立交易日历及预登记样本外折。到达 08:55 且五个持有日落在同一折内才计入。未核验的日历单列。
- 按时封存日只计已验证归档的预测。核查模型、决策与预测的绑定，复算基线与扩展预测值。每项比较的封存对数单列。
- 缺口按日展示，包括缺模型、缺输入、样本量不足、政策事件重复、归档迟到或校验失败。迟到记录保留实际时间，数值不进入正式读取结果。
- 交易日详情以该日截止时点查模型状态；较晚封存的模型可用于随后交易日。预测的后续评价另按五日标签的真实就绪时间配对。

首次验收时，独立研究仍在等待首个合格归档，应预测日和已封存预测均为 0。通过独立的已封存模拟归档验证端到端 API，覆盖数值复算、模型损坏后的剔除和迟到隔离。桌面与手机验证真实零值页和合成的预测详情。

下一步接通样本外误差统计、固定 50/50 及全债的经济对照，并持续核对真实采集与封存覆盖。
