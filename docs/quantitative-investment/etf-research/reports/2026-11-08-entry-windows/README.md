## 计算口径

起点日用收盘价生成目标，下一交易日开盘模拟执行，之后按月再平衡。沿用[四组市场组合](../2026-11-08-three-markets/)的费用、滑点、整手、可用现金、分红及开盘停牌处理。期末按人民币场内收盘价估值，包含已登记形成的应收股利，不另扣假设清仓费用。每个新起点从零持仓开始，此前不享有分红权益。旧报告的滚动统计从持续持仓的长曲线截取，本报告逐日起账。

目标日为公历周年日，2 月 29 日遇非闰年取 2 月 28 日，再取当天或之后的首个交易日。缺少完整持有期的起点不计入。净盈亏严格大于零才算赚钱。年化收益为 (期末资产 / 本金)^(365.25 / 实际日历天数) − 1，以未经展示舍入的结果判断是否达到 4%。[逐起点明细](entries.csv)保留期末资产、盈亏、累计与年化收益。[看板汇总](../../site/entry-windows.json)列出全部分子、分母及最差区间。

## 复现及核对

在项目目录运行，输出到新目录。

```sh
out=$(mktemp -d)
python scripts/build_entry_windows.py --output "$out/windows"
python scripts/verify_entry_windows.py "$out/windows/entries.csv" "$out/windows/entry-windows.json"
cmp "$out/windows/entries.csv" reports/2026-11-08-entry-windows/entries.csv
cmp "$out/windows/entry-windows.json" site/entry-windows.json
```

共核对 2,916 个满期结果。核验程序另行枚举周年终点、从期末资产重算盈亏和年化，按 4% 年复利所需期末资产核对达标次数。沪深300组与境内冻结策略实现逐个起点对照，其余各组使用同一四组引擎独立重跑至各自终点。固定起止日期与原报告对账，八组汇总从明细重算。
