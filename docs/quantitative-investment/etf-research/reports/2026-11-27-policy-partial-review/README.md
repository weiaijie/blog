# 政策来源部分缺证时保留可核验原文

一次采集可同时取得部分合格的官方原文，并留有另一来源失败的原始响应。工作台与 Agent 的待审队列现在能列出这批已通过原文哈希、网址、来源清单和实际收报时点核验的候选。队列保留来源不完整、首见回执及出现次数。已有相同网址和原文哈希的审核继续复用，正文修订照常独立登记。

部分采集可以生成审核草稿，只允许为该批已经核验的候选逐一封存审核结论。分歧及未取得的来源继续在覆盖台账留空。没有可核验原文的部分采集继续留在缺证列表，无法封存为空审核。审核完成只影响有正文、真实审核时点和分类记录的候选。完整采集计数和五个决策区间的覆盖仍按原有定时回执核对；缺完整采集的区间保持未知，政策特征不填零。零值范围限于已登记的目录和预定取证条件。 [政府要闻目录](https://www.gov.cn/yaowen/liebiao/YAOWENLIEBIAO.json) · [证监会主页](https://www.csrc.gov.cn/csrc/index.shtml)

隔离验收从已公开归档恢复真实官方候选和原审核。模拟一个来源失败后，已经核验的证监会关联公告仍出现在待审草稿，待审候选首见记录标记为覆盖不完整。部分采集可封存并复验原文分类。无法核验的空批次拒绝审核，五间隔真零不会被缺证补出。此前正式回放的 11 个已审版本和 1 个独立政策事件照常复算。 [队列回归](../../tests/test_observation_policy_queue.py) · [审核与五间隔回归](../../tests/test_observation_policy_review.py)

正式研究仍为 1 日归档、0 日合格。真实独立政策事件与正式预测输入各有原时点准入，隔离演练仅验证队列和审核分工。

1440 像素桌面和 390 像素手机均通过候选原文、不完整提示和待审计数检查，使用隔离响应。11 月 27 日 19:45 与 21:38 的实际待审队列已从公开归档还原并逐字段重算通过。
