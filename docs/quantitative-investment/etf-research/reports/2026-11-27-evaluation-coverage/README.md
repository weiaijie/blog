# 样本外评估进度与证据

工作台的「政策研究 → 样本外评估」列出政策事件、ETF 份额净值、沪市两融和全量增量四组。各组与量价基线在相同决策日配对，显示实际配对数、季度数、经济对照覆盖和距离门槛的缺口。最低要求为 120 个配对交易日和两个样本外季度，含政策组另需 20 个独立事件。各组评分和中期、结题口径见[样本外统计与经济对照](../2026-11-27-oos-evaluation/README.md)。

- `GET /api/v1/research/observation` 的 `evaluation` 返回工作台用的摘要。
- `GET /api/v1/research/observation/evaluation` 返回相同结构的摘要和最近一份已核验完整报告。指定 `?archive=<64 位 SHA256>` 可复查页面显示的那份归档。
- 摘要区分生成时点、证据核验时点和页面读取时点。较新报告损坏时保留缺口记录并回读较早已核验归档；损坏的指定归档返回 404。
- 截至代码联调，独立管线暂无合格归档。此时配对和事件计数为 0，评估时点留空。首个归档出现后，如果评估尚未生成，相应的评估统计保留未知。
- 隔离验收以独立临时归档检查实际哈希、未来时点屏蔽、归档直达和损坏回退。样本统计只随实际独立归档推进。
