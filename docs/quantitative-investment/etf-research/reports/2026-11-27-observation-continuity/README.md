# 独立采集首 20 个交易日的连续性核查

在工作台「政策研究 → 前瞻数据覆盖 → 首 20 个应采交易日」按日查看计划时点、归档证据、下一交易日 08:55 截止，以及官方政策、ETF 份额净值、沪市成交和两融分别何时就绪。Agent 查询 `GET /api/v1/research/observation/continuity`。可提供带时区的 `asOf` 按留存记录回看过去。

| 指标 | 计算口径 |
| --- | --- |
| 跟踪日数 | 按交易所已核验日历，从独立采集首日起最多 20 个交易日 |
| 有定时归档日 | 至少有一次定时服务的归档回执，手工结果另列 |
| 定时时点已核验 | 回执中的触发证据通过计划时点核验，服务启动分钟与实际触发时点须一致 |
| 按时合格 | 至少有一份完整定时归档在下一交易日 08:55 及之前取得 |
| 截止迟到或缺证 | 分来源取首次可用证据，使用来源就绪与归档核验的较晚时间 |

来源缺项在截止前显示等待，过截止后才计入连续缺口。迟到证据保留实际收报及核验时间。周末轮询可补齐上一交易日，周末本身不计入交易日分母。跨次尝试凑齐的单项数据可用于来源诊断，完整合格仍由同一份归档证明。
