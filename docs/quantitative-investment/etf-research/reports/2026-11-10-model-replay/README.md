# 逐日模型回放

在内网工作台选择日期、本金和费用，进入「逐日模型回放」。固定配比沿用组合 A 和调仓方式。120 日趋势使用冻结的境内股债规则，在首次建仓或月初，依据截至前收盘的沪深300含分红指数与其120个收盘均值，选择股债各半或全债。起点前须已有120个核验交易日，预热期间不计账户盈亏。回放支持一个组合，多组合比较继续用原入口。

首日为现金。每步显示截至收盘的场内日 K、目标持仓、开盘订单及佣金、收盘资产、现金、应收分红与回撤。单步接口只返回当前及过去的日线。下一开盘日期来自交易日历，模型定目标时尚不可使用该日的价格。「自动走完」一次取回同一模型逐日核算的完整记录，顺序播放，可暂停。查看的 ETF 只决定图中显示哪条日 K。

## Agent 调用

向 `GET /api/v1/backtest/replay` 传入工作台的六个参数，再传 `model=allocation` 或 `model=trend_120` 以及 `step=1`、后续正整数或 `all`。趋势模型固定使用 `weights=1,0,0,1&rebalance=monthly`。返回的 `totalSessions` 是区间的交易日数，`frames` 包含已请求的逐日结果。末日不再生成下期计划。价格和账户金额以十进制字符串传输。

示例：`/api/v1/backtest/replay?start=2024-10-30&end=2024-11-08&capital=100000&weights=1,0,0,1&rebalance=monthly&fees=base&model=trend_120&step=2`。

## 复核

Ubuntu 上运行 `PYTHONPATH=src python -m unittest discover -s tests -p test_model_replay.py -v`。用真实样本物理移除游标之后的价格、公告和停牌记录，并逐帧对照原区间的信号、订单、持仓和权益。固定配比对照工作台全程回测，趋势模型对照冻结引擎。交易价格遵循原模拟滑点与成交限制，不能作为实际成交证明。
