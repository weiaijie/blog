# 两至三套自定义配比并排比较

在局域网看板「自己运行回测」填好日期、本金、费用和调仓方式，点击「添加对比组合」，分别设置组合 A、B，按需再添加 C。每套的四项配比依次对应沪深300、标普500、恒生和国债。点击「并排比较 · 测 1 年和 2 年」即可查看两个期限的对照表。点击某一列的「查看回撤」可查看该组合最差一期的逐日资产、回撤、峰谷、恢复日期及订单。「重开本次比较」链接会保留共享设置和各组配比。

### 统计口径

所有组合按同一交易日历与相同起点重新从现金建仓，比较选定区间内满期的窗口。赚钱按到期净盈亏大于零计算，年化达标按实际日历天数折算的年化收益大于等于 4% 计算。周年休市顺延至下一交易日，闰日遇非闰年取 2 月 28 日。各组合分别按到期盈亏选出最差一期，并列时打开最早起点。没有满期窗口时显示样本数 0、最差期为空。重叠窗口的比例仅描述本段历史。[单组合计算口径](../2026-11-08-custom-windows/README.md)

### Agent 入口

使用同一份六参数。日期、本金、费用、调仓方式各传一次。`weights` 按输入顺序用竖线分隔两套或三套配比。通过 `GET /api/v1/backtest/options` 可发现接口路径与配比格式。

```sh
curl --fail-with-body 'http://10.1.1.120:18766/api/v1/backtest/compare?start=2023-10-30&end=2026-10-30&capital=100000&fees=base&rebalance=monthly&weights=1,1,1,3%7C3,1,0,6%7C1,0,0,1'
python scripts/interactive_backtest.py --compare --start 2023-10-30 --end 2026-10-30 --capital 100000 --fees base --rebalance monthly --weights '1,1,1,3|3,1,0,6|1,0,0,1'
```

结果 `portfolios` 按 A、B、C 排序，各项的 `parameters` 保留该组实际参数。`periods["1"]` 和 `periods["2"]` 含 `count`、`profitable`、`reached`、有样本时的 `worstPnl` 及 `worstReplay`。最差期的 `daily`、`summary` 和 `orders` 与同配置的单组合回放共用实现。

以上示例为 10 万元、全历史、基准费用、每月再平衡。每组一年均有 486 次满期，两年均有 243 次。

| 持有期和指标 | A · 1/1/1/3 | B · 3/1/0/6 | C · 1/0/0/1 |
|---|---:|---:|---:|
| 1 年赚钱次数 | 477 | 479 | 466 |
| 1 年年化 ≥ 4% 次数 | 455 | 459 | 444 |
| 1 年最差到期盈亏（元） | −2,735.21 | −2,080.47 | −5,848.32 |
| 2 年赚钱次数 | 243 | 243 | 243 |
| 2 年年化 ≥ 4% 次数 | 243 | 242 | 233 |
| 2 年最差到期盈亏（元） | +10,053.28 | +7,957.72 | +5,782.62 |
