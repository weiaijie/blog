# 独立研究 6 个月中期复盘归档

每日评估在实际首个合格归档日起满六个月后，第一次运行时以周年日北京时间 00:00 为固定证据截止，封存中期复盘。分别保留预期和已合格的归档日、决策就绪和五日标签、期间新增的独立政策事件，以及各比较组的成对日期、样本外季度和排除原因。有缺失日历时保留已知范围。政策证据未通过则保留未知。

后续日报沿用已通过内容核验且起点与截止一致的中期记录。工作台的「样本外评估」展开「6 个月中期复盘」可查证据时点及覆盖。Agent 通过 `GET /api/v1/research/observation/evaluation` 查询同一份 `midtermReview`，可用 `archive` 固定评估归档。复验时将封存的 `report` 对象交给 `scripts/observation_out_of_sample.py --verify`，按原时点重算。中期只报告覆盖与缺口，按协议在满 12 个月后核对统计和经济结果。
