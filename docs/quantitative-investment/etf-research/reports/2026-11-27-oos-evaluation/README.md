# 样本外误差与经济对照

评估程序按模型、预测、实际标签的独立归档核验同一天的数据，保留缺预测、缺标签、逾时、政策跨折重复或归档损坏原因。五个持有日须处在同一预登记样本外折。中期只报告覆盖、折内样本数、独立事件数和缺口。12 个月届满、交易日历和最后一段标签核对后才进入统计。尚待完成的标签保留待核验状态，已证实的缺口单列。

误差使用五日净收益和最大收盘回撤的成对 MAE，保留各折实际样本数、原交易日的缺失位置和区块抽样区间。正式门槛固定为 120 个不同决策日、至少 2 个样本外折，含政策的比较另需 20 个独立事件。全量增量是主要检验，其他比较用作探索。

经济对照先在完整交易日历逐折选不重叠窗口，随后匹配同日起点的基线、扩展预测和实际标签。有缺口时保留原日期。逐期对照固定股债各半、全债、基线选择和扩展选择，覆盖低、基准、高三档费用。对照表记录净收益、最大收盘回撤、佣金、滑点、结算现金、可用现金、应收分红与未足量成交。先核对收盘净值、收益、回撤和整手，缺现金证据的旧标签仍保留未知。汇总采用窗口均值。原有 18 户长期年化按该组实际观察期单独报告。

- [真实状态](status-probe.json)在独立生产归档生成并按原时点复核。首次合格归档尚未产生，暂无正式比较。
- 隔离试验覆盖跨折政策事件、未完成标签、样本及事件门槛，验证主比较区间与探索输出。验证已封存报告的恢复与损坏拒绝。合成样本用于验收。
- 独立 Ubuntu 的评估定时器安排于北京时间 20:45，归档实际核验完成时间。首次例行执行须查运行回执。
