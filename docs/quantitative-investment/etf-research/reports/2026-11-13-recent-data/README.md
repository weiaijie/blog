## 如何使用

1. 打开[新版工作台](http://10.1.1.120:18766/workbench/)，在“研究设置与保存”选择“近期核验版 · 截至2026-11-12”。
2. 设置日期、本金、费用及1至3套配比；模型回放点“从第一天开始”，逐日查看收盘决策与下一交易日订单。标普2022年拆分缺报价区间仍禁止跨越。
3. 组合比较可选配比、四种投资方式、技术因子；看一年/两年赚钱次数、达到4%次数及最差盈亏，打开最差期看叠图、逐日归因和买卖因子。
4. 保存、导出或分享方案时携带数据版本。旧version=1方案自动标记原冻结样本，恢复时不会默默切到新样本；修改数据版本会清空当前结果。
5. 导出Agent请求清单使用同样参数与版本。新版路径/api/v2/backtest，原/api/v1/backtest继续固定旧样本；未知操作拒绝，超过核验末日拒绝。结果带dataVersion和admittedThrough。
6. Agent也可在项目目录运行：PYTHONPATH=src python scripts/recent_backtest.py --operation replay --params '<同接口的字符串参数JSON>'。操作支持account/windows/compare/overlay/replay/method-windows/method-detail/technical-factors/technical-detail。

模型和费用公式未更换；新旧数据采用请求内上下文与带版本的缓存隔离，防止并发请求互相切换数据。新增到期窗口重新计算，不拿旧CSV冒充新统计。原专题报告依旧采用其自身已归档参数。

## 默认长样本响应

默认2019-03-20至2026-11-12、本金10万元、基准费用的投资方式及技术因子比较已从新数据完整重算：各有1614个一年窗口、1371个两年窗口。方法比较首次计算259.937秒，技术比较29.708秒，见[运行耗时](default-timings.json)。

为避免每次打开默认方案等待，服务仅对这一组完全相同的参数读取本轮新报告并校验SHA256（隔离服务实测约0.476秒/0.001秒，见default-http-timings.json）；自定义参数仍实际计算，不偷换旧样本。新结果见[四种投资方式](default-methods.json)及[技术因子](default-technical.json)。离线复算可运行PYTHONPATH=src python scripts/build_recent_results.py --output <新的空目录>；它直接调用计算层，绕过响应归档。
