# 独立政策研究的待审队列

工作台「政策研究 → 前瞻数据覆盖 → 政策审核与关联公告」显示待审稿件、重复出现次数及原文入口。Agent 使用 `GET /api/v1/research/observation/policy-queue`，可带 `asOf` 查询对应时点已封存的候选和审核。当前状态、待审版本与事件审核结果来自同一截止时点。

- 只从可核验的政策归档识别版本。一个官方网站 URL 的同一原文 SHA256 只产生一个待审条目，并保留首次和最近一次采集回执。相同网址出现新字节时留下新的版本及旧版本指针；随后恢复旧页面也能找到先前出现的新版本。
- 已审核的相同版本可复用原分类、原文定位和理由。未审版本的分类留空。空结果待确认、不完整响应和缺归档分别列出，避免把来源失败计为空列表。
- 依照原工作流封存审核。政策事件的实际可用时间仍由原始证据、审核回执和盘前截止决定。
