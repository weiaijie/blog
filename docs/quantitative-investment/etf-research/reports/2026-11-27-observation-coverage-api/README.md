# 前瞻采集覆盖看板与 Agent 验收

工作台「政策与市场研究」增加「前瞻数据覆盖」。每天列出政策原文、510300 与 511010 份额净值、沪市成交、沪市两融及归档次数。点日期可以展开定时采集和补抓、实际开始及归档时刻、就绪时间、缺口和归档校验值。保留计划外手工复查，进度只计经日历确认的计划内交易日。

## 共用接口

| 请求 | 内容 |
| --- | --- |
| `GET /api/v1/research/observation` | 计划日、已有归档、合格归档及未见采集天数，首个合格归档、复盘和结题日期，最近 30 个有记录或应采的交易日。 |
| `GET /api/v1/research/observation?day=2026-11-27` | 当天的字段覆盖、每次归档和异常。 |
| `GET /api/v1/research/observation?before=2026-11-26` | 从给定日期（含）向前翻页。后续使用 `nextBefore`。 |

接口读同一台 Ubuntu 的独立前瞻采集工作目录和内容寻址归档。读取时复核归档清单与尝试清单、结果哈希、交易日历及归档凭据。整套账本不可用时返回 HTTP 503。个别尝试的回执缺失或无法通过核验时明确列出对应日期，合格日期只使用通过核验的回执。同日后续复查留下单独记录。未知年份的正式日历不会抹去此前已核验的已知交易日。

合格归档数衡量采集进度。正式统计还须完成五日标签并达到[研究计划](../../docs/LONG_TERM_RESEARCH.md)的样本和独立政策事件要求。政策候选原文已归档的时间是取证记录，实际审核和模型特征可用时点仍按事件规则判断。
