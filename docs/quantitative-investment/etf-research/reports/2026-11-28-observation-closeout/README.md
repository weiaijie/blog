# 从公开证据恢复并生成 12 个月结题报告

结题程序从 GitHub 检出的公开目录验证基础包、全部登记增量和链尾，恢复原始回执与对象。只有已通过日历、盘前决策、预测、五日标签和评估归档门槛的记录，才能用于结题。程序核对归档中的预登记协议哈希，再按评估当时的时点重算全文。未找到起点、证据待核验、标签待封存及经济对照异常都有自己的状态。证据完整但低于预登记门槛时，报告给出实际样本量、排除原因及样本不足结论。

在 Ubuntu 的 GitHub 检出目录进入 ETF 项目运行以下命令。应使用固定提交，以复现该次发布的证据范围。已有结题报告时，可额外传入其评估归档 SHA256 的 `--archive` 参数。

```bash
PYTHONPATH=src python scripts/build_observation_closeout.py --output reports/closeout
```

状态为 `ready` 时生成 `README.md` 和 `result.json`。包含四组配对覆盖、主要比较的误差及区间、非重叠窗口经济对照、各项费用和原 18 户同一证据时点的进度。12、24 个月账户复盘各自按已核验的发布回执可用时显示净年化。任一前置状态未满足时，命令输出当前状态，结题目录尚未生成。

## 核验结果

当前已公开的链路恢复后，工具显示「等待首个合格归档」。另用现有公开原始档案和 2026 年真实日历，隔离模拟完整 12 个月到期，封存、读回并逐字段重算评估。诊断场景下四组为样本不足，仍能读取实际 18 户已发布的 16 个收益区间。诊断结果未进入正式研究。 [实证与隔离结果](verification.json) · [预登记门槛](../../PROTOCOL_OBSERVATION_V1.md)
