# 五交易日标签覆盖与就绪时点

工作台「政策与市场研究」和 Agent 共用 `/api/v1/research/observation`。总览新增 `labelCounts`。交易日查询 `?day=YYYY-MM-DD` 返回 `session.label`，包含固定持有日期、到期时间、实际就绪时间、归档校验值、证据缺口和可复现的结果。

- 持有期未满按独立交易日历计算。第五个交易日 16:00 起进入到期窗口。
- 标签就绪采用独立内容寻址归档实际核验完成时点。只有与合格决策的回执哈希、交易日及五个持有日期一致的标签可计数。
- 到期缺口包括证据不足、等待封存、归档中断和校验失败。缺行情、开盘或分红证据的日期单列。日历未知的候选单列，仍待核验日期。
- 同一窗口的后续尝试保留，首次通过核验的结果及原就绪时点持续使用。较晚到达的回执只能从真实就绪时点开始使用。

首次现场验收时，尚无合格决策和到期标签，四项总览显示 0。历史缺口验证继续看[11 月 23 日入场窗口](../2026-11-27-five-session-labels/README.md)。在独立环境核对了实际归档的控制实验，包括晚到证据、损坏回执、异版本决策、持有期未满和首次有效版本的选择。桌面和手机使用同一个日期查询。带收益和开盘缺口的页面回执通过隔离数据验收。

下一步将合格决策与标签按各折实际就绪时点接到训练和预测封存，保持预登记的样本量、时间切分及成本。
