# 自定义配比的逐日起点回测

在内网历史看板的「自己运行回测」填好日期、本金、四只 ETF 配比、费用和调仓方式，点击「逐日起点 · 测 1 年和 2 年」。按钮一次计算两个期限。「用全部可用日期」会将区间设为 2023-10-30 至 2026-10-30。点击某行的「查看最差期回撤」，可以查看该次单独建仓的逐日收盘回撤、总资产、前高、谷底和恢复日期，并下载该次订单。保存「重开逐日起点设置」链接即可重跑同一配置。

### 如何读结果

选择区间内的每个交易日分别以所填现金本金起步。周年日休市顺延至下一交易日，闰日的一周年落在次年 2 月 28 日，仅纳入在区间内到期的窗口。盈利按净盈亏大于零计算，达标按未舍入的实际日历天数复合年化收益大于等于 4% 计算。最差按到期净盈亏排序；并列时展示最早起点并记录并列次数。回撤曲线按窗口内此前最高收盘账户资产逐日计算。窗口相互重叠，次数和占比描述所选历史。

例如全区间、10 万元、沪深300／标普500／恒生／国债配比 3、1、0、6，采用基准费用、每月再平衡。

| 期限 | 满期 | 赚钱 | 年化 ≥ 4% | 最差到期盈亏 | 起止日期 |
|---|---:|---:|---:|---:|---|
| 1 年 | 486 | 479 | 459 | −2,080.47 元 | 2025-10-30 至 2026-10-30 |
| 2 年 | 243 | 243 | 242 | +7,957.72 元 | 2024-10-22 至 2026-10-22 |

### Agent 调用

`GET /api/v1/backtest/options` 返回接口路径与参数。逐日起点接口接受与单次回测相同的六个参数。网页、HTTP 和离线命令运行同一模拟逻辑。

```sh
curl --fail-with-body 'http://10.1.1.120:18766/api/v1/backtest/windows?start=2023-10-30&end=2026-10-30&capital=100000&weights=3,1,0,6&rebalance=monthly&fees=base'
python scripts/interactive_backtest.py --windows --start 2023-10-30 --end 2026-10-30 --capital 100000 --weights 3,1,0,6 --rebalance monthly --fees base
```

JSON 的 `periods["1"]` 与 `periods["2"]` 分别给出满期次数 `count`、赚钱次数 `profitable` 和达标次数 `reached`。有满期样本时，`worstPnl` 是最差到期盈亏（人民币元），`worstReturn` 是累计收益率。`worstReplay` 包含该次参数、每日回撤、账户资产、汇总和模拟订单，采用[单次回测格式](../2026-11-08-interactive-backtest/README.md)。某期限没有满期窗口时，次数为 0，`worstReplay` 为 null。

[归档的固定配比逐日起点结果](../2026-11-08-entry-windows/)用于交叉核对四个预设。回归检查覆盖八组统计、最差期逐日回撤、不同本金及费用、非等权分配、周末周年、闰日、并列与缺少满期样本。
