# ADX 与同日起点纯国债核对

2026-11-11。固定此前三因子＋ADX规则，新增纯债与一次建仓股债各半的同参数对照、逐日归因、年度和非重叠样本。没有修改原模型或前瞻账户。

## 先看结论

ADX两年赚钱1359次，并不能证明择时很有效：同期纯国债赚钱1361次。ADX在1362个两年窗口中只有746次超过纯债，616次落后；以2021年交易日起步的243个两年窗口全部落后纯债。完整区间确有正的持股时段贡献，但分期结果不稳定，尚不足以认定具有可重复的预测能力。

## 看板与操作

- 打开 backtest.html#adx-bond，填共同开始/结束、本金和费用，比较ADX、纯债和一次建仓股债各半。
- 持有期切换1/2年。点击各账户最差一期、ADX相对纯债落后最多的一期、某日历年或某条非重叠链的一期，可查看同期净值、回撤、逐日分项、持仓、信号和订单。
- 年份有两种口径：日历年保留连续账户，起点年份则汇总该年新建现金账户的满期结果，两者不混用。
- 所有功能与Agent共用同参数API。默认归档带SHA256校验；自定义参数实际重算，不套用默认结果。

## 同日起点、相同本金与费用

默认每户10万元，base费用，2019-03-20至2026-10-30。预热行情只计算指标，账户从现金开始。

| 持有期 | 满期数 | ADX赚钱 | 纯债赚钱 | ADX年化≥4% | 纯债年化≥4% | ADX胜/负纯债 |
|---|---:|---:|---:|---:|---:|---|
| 1年 | 1605 | 1548 | 1527 | 680 | 252 | 876 / 729 |
| 2年 | 1362 | 1359 | 1361 | 555 | 41 | 746 / 616 |

ADX两年最差盈亏−1,954.06元（2021-02-10～2023-02-10），同一期纯债盈利6,008.43元，ADX少赚7,962.49元，也是两年相对纯债最差的一期。纯债自己的两年最差为−1,482.68元，发生在另一窗口，不能把各自最差当同日对比。

重叠窗口共享大量行情，不是1362次相互独立的试验；本次历史策略的原型已用该样本研究过。

## 完整区间：少持股票与时机的不同作用

| 账户 | 净盈亏 | 最大收盘回撤 |
|---|---:|---:|
| ADX原规则 | 28,647.79元 | -7.26% |
| 只持国债 | 22,990.85元 | -4.61% |
| 一次建仓股债各半 | 21,750.49元 | -20.32% |

ADX比纯债多赚5,656.94元，平均实际股票敞口约10.02%。按[固定分解口径](PROTOCOL.md)：

| 分项 | 贡献 |
|---|---:|
| 平均股票敞口（事后） | 717.15元 |
| 持股时段匹配（事后） | 6,259.16元 |
| 开盘换仓后的日内贡献 | 2,441.90元 |
| 历史盈亏形成的资本差 | 613.11元 |
| 现金及应收的国债机会成本差 | -120.37元 |
| 分红登记权益差 | 0.00元 |
| 佣金差 | -1,474.21元 |
| 滑点差 | -2,779.80元 |
| 显示舍入差额 | 0.00元 |

持股时段匹配6,259.16元＋换仓后的日内贡献2,441.90元−额外佣金/滑点4,254.01元＝4,447.05元。这说明本区间存在正的时段贡献，但仅是这套账户分解下的历史观察；还包含另外三个基础因子的共同作用，不能当作ADX单指标的因果收益。

平均股票敞口从完整区间事后求得，只用于收益恒等式，不是当时可知的固定配置策略。其他资本差、现金及应收机会成本、登记权益差单列，避免全部差额都被称作择时。逐日展示使用累计舍入差分，使每项逐日加总也与期间汇总一致。

与一次建仓股债各半相比，股票下跌日的股票贡献差合计+322,533.90元，上涨日合计−322,121.30元，互相抵消后股票净贡献差只有+412.60元；国债贡献差+10,735.35元，再扣额外佣金和滑点4,250.65元，合计多赚6,897.30元。两个三十多万元数值是逐日机会成本对照，并非实际赚到的钱，也不能仅展示下跌日的好处。

## 不重叠核对

默认以2019-03-20为锚：1年链7期中胜纯债3期；2年链3期中胜1期。每期重新投入同样本金，边界收盘可共享，收益日不重复；不能把这些现金重置账户拼成一条真实投资曲线。

默认2年链：

| 开始 | 满期 | ADX相对纯债差额 |
|---|---|---:|
| 2019-03-20 | 2021-03-22 | 5,362.39元 |
| 2021-03-22 | 2023-03-22 | -3,005.53元 |
| 2023-03-22 | 2025-03-24 | -721.00元 |

随后11个月首个交易日的锚点也全部保留。12条两年链各只有3期，胜纯债1～2期；一年链各6～7期，胜2～5期。不同链彼此重叠，不合并胜率，也不挑表现最好的链作主结论。未满期尾段单列不计。

## Agent与复现

```sh
PYTHONPATH=src python scripts/adx_bond.py --start 2019-03-20 --end 2026-10-30 --capital 100000 --fees base --output /tmp/new-adx-bond.json
PYTHONPATH=src python scripts/adx_bond.py --detail --start 2021-02-10 --end 2023-02-10 --capital 100000 --fees base --output /tmp/new-adx-case.json
PYTHONPATH=src python scripts/adx_bond.py --detail --year 2022 --start 2019-03-20 --end 2026-10-30 --capital 100000 --fees base --output /tmp/new-adx-year.json
```

- GET /api/v1/backtest/adx-bond?start=2019-03-20&end=2026-10-30&capital=100000&fees=base
- GET /api/v1/backtest/adx-bond-detail?start=2021-02-10&end=2023-02-10&capital=100000&fees=base：现金重置区间。
- GET /api/v1/backtest/adx-bond-detail?start=2019-03-20&end=2026-10-30&capital=100000&fees=base&year=2022：原连续账户的2022年切片，不是新建账户。
- 参数错误返回400；归档哈希或会计核对失败阻断，不伪造成功。CLI输出要求新文件，不覆盖旧证据。

## 边界与下一步

本轮只用此前已准入的人民币未复权行情与官方分红，未新增行情、未放宽保护、未更改18个前瞻账户、ADX规则或旧结果。保留实盘撮合、正式除息参考价和完整停复牌证据的既有缺口。

目前可以说：相对股债各半，低股票敞口减少了某些阶段的损失；相对纯债，ADX在全期增加了收益和风险，但并非各年/各起点都有效。下一步应保持规则不变，先核对额外成本与持仓时长的敏感性，若另试确认天数或分档仓位，另立版本并保留本轮反例。

原技术栈继续使用pandas、NumPy和TA-Lib；账户仍由冻结执行引擎计算。本轮未添加新依赖，也没有用测试通过代替收益目标验证。验证与页面证据见[VALIDATION.md](VALIDATION.md)。
