## 标普开盘停牌与账户权益

## 查询和复核

[内网看板](http://10.1.1.120:18766/workbench/#/changes/nov20)可切换模型或基准、持有期限，展开逐个到期窗口、新旧最差一期及停牌拦单。看板和 Agent 共用[版本比较 JSON](comparison.json)。逐单清单在 controls，各场景的 periods 中提供 before、after、delta、sampleEffect、haltEffect 与 newWindows。

Agent 可请求 `GET /api/v3/backtest/data-change`，取 cases 中的标识，再请求 `GET /api/v3/backtest/data-change-detail?case=market-sp500-initial-2026-11-16`。归档的11月12日对比使用 v2。

```sh
PYTHONPATH=src python scripts/november_change.py --output /tmp/six-session-comparison-new.json
PYTHONPATH=src python scripts/november_change.py --case market-sp500-initial-2026-11-16
```

复算先核验[新版行情与公告](../2026-11-22-admission/README.md)及[旧版逐窗比较](../2026-11-13-data-change/README.md)。境内模型从封存逐窗结果续算，汇总与11月20日完整重算结果逐项核对。四组基准用11月12日数据重跑旧窗口，逐项核对旧报告，再用11月20日数据计算新窗口。旧日历、分红、价格、停牌限制均沿用已核验前缀。
