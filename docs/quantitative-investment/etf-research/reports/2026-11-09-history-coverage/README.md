沪深300与国债各半单独从 2018-09-14 开始，10 万元至期末为 137,767.98 元，年化 4.02%，最大收盘回撤 19.73%。逐日现金、应收分红、持仓及总资产均与冻结的 1,967 行账户记录一致。两种样本的起止日和覆盖市场不同。

```sh
python scripts/interactive_backtest.py --start 2018-09-14 --end 2026-10-30 --weights 1,0,0,1
python scripts/interactive_backtest.py --windows --start 2023-01-03 --end 2026-10-30 --weights 1,1,1,3
```

Agent 可通过 `/market-data.json` 取得各 ETF 的日期和四价；`/api/v1/backtest/options` 的 `first`、`domesticFirst`、`last` 提供回测边界。历史模拟与前瞻观察各自计数。
