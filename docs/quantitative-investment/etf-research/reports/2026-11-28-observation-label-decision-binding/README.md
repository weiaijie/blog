# 五交易日标签统一绑定盘前决策

盘前任务重试、标签调度、工作台和 Agent 现在都按已核验的实际封存时间确定同一日的盘前决策。当天若已有第一份截止前通过核验的封存，其状态及可用模型沿用该份决策。

标签必须绑定选中决策的路径、归档哈希和回执哈希，同时对上起算收盘、五个交易日、最后交易日及到期时刻。定时任务只接受当前核验时点已经收到的标签。先前绑定了不同决策的标签保留在历史中并给出失败原因。仍无正确标签时，窗口继续等待核验。Agent 同日查询的 `session.label.attempts[].evidence` 提供决策、逐日行情、开盘归档回执和缺口来源，供复算使用。

## 核对结果

- 隔离生成两份截止前封存的决策，较晚一份的目录编号更小。盘前重试、到期标签调度和覆盖查询均选中封存更早的一份。
- 错版标签完整归档后，到期窗口仍进入待核验队列。正确标签按实际就绪时点开始可用，旧的错版与失败记录仍可查。
- 11 月 23 日历史验证窗口从原证据复算，前收盘和五个收盘全部核实。两只 ETF 的开盘证据缺失，收益和回撤留空。[真实历史窗口](../2026-11-27-five-session-labels/label-validation.json)
