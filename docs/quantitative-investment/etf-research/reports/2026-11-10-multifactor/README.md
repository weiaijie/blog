# 多因子 v1 · 境内股债逐日模拟

在看板“逐日模型回放”选择“多因子 v1 · 每日两票触发”，点击“开始回放”。每步可看三项读数、投票、收盘目标、下一开盘的模拟成交与未成交原因；展开“截至当日的信号与模拟成交”可查看历史切换。用户可选择回测起止日、本金和费用，买卖由模型决定。

## 决策规则

| 每个交易日收盘各投一票 | 满足条件 |
|---|---|
| 长期趋势 | 沪深300含分红指数收盘水平 ÷ 最近120个收盘均值 − 1 > 0 |
| 股债相对强弱 | 最近60个交易日沪深300 ETF 含分红收益率减国债 ETF 含分红收益率 > 0 |
| 短期波动 | 沪深300最近20个日收益率的样本标准差 × √252 < 25% |

从已核验行情逐日累乘（当日收盘价 + 当日已公告的每份除息额）÷ 前收盘价。两个标的是 510300 和 511010。开始前需要 120 个收盘供预热，账户在选定起点才开始记账。三项相等于各自阈值时均不计为满足。两票或三票对应股债各半；零票或一票对应全债。趋势与相对强弱都使用股票行情，三票可能相关。25% 为本研究版本固定参数，未对收益择优调参。

首次确定目标或目标切换时，按当日权益与收盘价取整至100份，下一交易日开盘先卖后买。账户使用既有整手、现金、停牌、除息保护、费用、滑点和分红记账规则。目标持续时持仓自然漂移。部分成交或拦截记录实际模拟份额，剩余量等到下一次目标切换才重新计算。末日仍展示投票，区间外不模拟成交。

长区间使用全部共同准入日期，含短案例。基准费用相同，期末金额已扣模拟成本。长区间共80次目标指令，其中一次订单成交不足；佣金列仅统计实际扣取的佣金。短案例中，2021-11-03 股指低于均线 3.474%，股债60日收益差 -1.848 个百分点，年化波动 12.552%。仅波动项通过，转为全债；11-04 模拟卖出 10,000 份沪深300，买入 300 份国债。完整结果含逐笔核查的首个切换示例。[可复算结果](results.json)

## Agent 与复算

- 读取 `GET /api/v1/backtest/options` 的 `multifactorV1`，使用 `GET /api/v1/backtest/replay?model=multifactor_v1&step=5&start=2021-10-29&end=2022-10-31&capital=100000&fees=base&weights=1,0,0,1&rebalance=signal`。step 可为正整数或 all。
- 每帧的 decision 是当日收盘投票，nextPlan 为下一开盘计划，orders 为本日实际模拟执行。三者各自带日期。固定采用相同规则，无人工确认或下单环节。
- 在项目环境运行 `python scripts/check_multifactor.py` 可重建两段结果。测试另以 pandas 重算滚动因子，并截掉未来行情核对回放前缀。该模型属于历史研究版本，前瞻账户继续按已冻结协议记账。
