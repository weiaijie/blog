# 阶段一：独立执行对照完成，冻结引擎暂不迁移

大目标仍在进行中：风险扩展和每日流程尚待完成，不能把本阶段当作整个项目交付。

## 实际实现与对照范围

使用Backtrader 1.9.78.123原生BackBroker执行订单、更新现金与持仓，ETF适配负责分红权益/到账/可用时间、整手、T+0/T+1、禁止卖空、费用分币、不利刻度、先卖后买、一次性现金裁剪、除息日与9%研究缓冲。没有调用原Ledger进行新引擎记账。

通过[冻结引擎目标](matrix.json)驱动独立执行：共享目标日期和目标份额，不把原成交份额或价格喂给新引擎。**这不是独立信号生成验证，也不是成熟引擎默认支持所有中国ETF规则的证明。** `cheat_on_open`仅用于在开盘阶段提交已固定的目标；当日收盘、高低价不参与目标重算，另有变形测试。

参考官方接口：[开盘执行时序](https://www.backtrader.com/docu/cerebro/cheat-on-open/cheat-on-open/)、[佣金扩展](https://www.backtrader.com/docu/commission-schemes/commission-schemes/)。运行时核对过固定版本BackBroker源码；适配调用其内部`_execute`，升级版本必须重新对照。

## 核验结果

- 1967个历史交易日，6策略×3费用×3本金×3延迟，共162场景。
- 2,382,920项字段比较，6,674笔原生交易记录；最终[差异列表](differences.json)为空。
- 单位、决策、事件、刻度归一后的交易价格/金额/费用严格相同；日现金/净值浮点容差预先设为0.0000001元，实测最大差0.0000000007元。该数值容差只用于程序浮点比较，不修改行情准入精度或交易规则。
- [native_fills.json](native_fills.json)保留原生成交价、费用和归一差。原生均价可能因float乘除出现尾差；只有误差不超过0.000000001元且归一后等于预定0.001元刻度价格才接受，原生现金和持仓没有被强制改成旧结果。
- 120项原测试与18项专门边界测试通过。边界覆盖分红资格、登记后卖出仍获分红、登记后买入无权益、发放日不可用、周末到账、T+0/T+1、半分舍入、卖税、现金不足、整手/卖空拒绝、先卖后买、延迟、缺失行情、复权输入和同日信号拒绝。

## 明确的不可迁移反例

合成样例：现金107.60元、价格1.026元、100份、最低佣金5元、无滑点。Decimal账本恰好花完107.60元并持100份；Backtrader原生float计算会出现约-1.42e-14元的临时余额，从而触发Margin并拒单。该反例记录在`test_exact_cash_boundary_is_known_native_difference`，测试通过表示**已稳定识别差异**，不表示两边相同。

不能通过偷偷添加现金或放松准入来掩盖这个边界。因而本轮只交付隔离对照工具，冻结前瞻仍用原引擎。未来若替换需先解决原生现金边界并重新走完整矩阵及前瞻并行验收。

同样保留成本模型可超出日内高低价的口径，与原生默认高低价撮合不同；对照相同不证明真实成交。收益目标不参与选型或调参。

## 复现与来源

```sh
python -m pip install -r requirements-backtrader.txt
PYTHONPATH=src python -m unittest discover -s tests_optional -v
python scripts/compare_execution_matrix.py --output reports/新的独立对照目录
```

输出目录必须不存在。`matrix.json`含实现SHA256、数据来源和每个目标序列哈希；本目录保留运行开始时的源代码副本。首轮探索目录`2026-11-06-engine-matrix`保留1366项浮点尾差：其旧工具在运行末尾取代码指纹，期间源文件已变化，因此不作为版本验收依据；v2和本final目录改为运行开始捕获源码。最终以本目录及对应Git提交为准。
