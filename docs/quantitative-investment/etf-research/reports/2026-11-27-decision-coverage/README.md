# 08:55 决策封存覆盖看板

人工在工作台「政策与市场研究」查看前瞻数据覆盖。Agent 读取同一个只读接口 `/api/v1/research/observation`。两者使用独立封存回执与内容寻址归档的核验结果。

| 项目 | 核对口径 |
| --- | --- |
| 已到截止 | 自首个启用后的交易日 2026-11-30 起，独立日历已确认且 08:55 已过的决策日。 |
| 按时封存 | 有完整回执和归档，实际归档核验不晚于截止，包含仍缺输入或等待研究起点的记录。 |
| 可入样候选 | 按时封存、研究已经起算且量价基线齐备。五个交易日的收益及最大回撤标签随后核验。 |
| 封存缺口 | 已到截止的日期缺完整、按时且可核验的输入封存。迟到、失败、未见封存和校验失败保留其他可见原因。 |

总览新增 `decisionCounts`、`nextDecision`、每行的 `decision`。当日查询 `?day=YYYY-MM-DD` 包含 `session.decision.attempts`、输入覆盖、各字段缺口及归档校验值。未收盘交易日可以已有决策回执。试跑保存在独立的验证目录，页面计数只读生产决策回执。

11 月 27 日首次现场验证时，正式决策数与可入样候选均为 0。11 月 27 日的日级查询显示封存启动前，下一次计划为 11 月 30 日 08:52。真实试跑和恢复凭证继续保存在[定时封存验收](../2026-11-27-decision-seal/README.md)。

在 1400 像素桌面和 390 像素手机宽度核对真实总览、日期明细及同日 Agent JSON。另用隔离浏览器响应验证已封存回执的输入缺口和校验值展开，假设数据仅用于界面测试。后续接通五日标签并确认例行封存产物。
