# 政策事件归并与按时点原文核验

独立前瞻研究要求含政策的比较至少有 20 个经核验的独立事件。同一官方 URL 的新正文和多地址发布的相同正文都纳入同一事件链。审核封存串行核对既有账本，已经入链的 URL 或原文 SHA256 不能另建事件。同一修订的分类、来源角色以及已登记事件的主题、阶段在后续审核中保持一致。取得新正文后可以追加同一事件的来源版本，按过去时点查询仍仅返回当时已就绪的证据。不同正文之间的语义关系由审核明确归并。

## 生产原文复验

[可复核快照](verification.json)对照了 11 月 27 日晚间审核前后。晚间审核前有 10 个原文版本、1 个独立事件及 0 条关联公告。晚间审核后有 11 个原文版本、1 个独立事件及 1 条关联公告。独立事件下有 2 条已核验来源，关联公告保留自己的取证时点。政策覆盖为 0/5 个区间，入模事件数仍为空。此项验收用于防止未来的独立事件计数膨胀。

工作台进入「政策与市场研究」中的「政策审核与关联公告」，展开「独立事件的原文依据」可查看审核时点、版本和官方原文。Agent 通过 `/api/v1/research/observation/policy-review` 或 `/api/v1/research/observation/policy-queue` 获得同一时点的 `independentEvents`。

定向测试模拟同地址正文修订、同正文换地址、多时点回查和分类修改，验证允许同一事件的新版本并阻止重复计数。此前审核原文和归并依据见[晚间审核复验](../2026-11-27-policy-followup-verified/README.md)。
