### 看板与核对口径

进入「组合 A · 1 年最差期同区间对比」，图的第三层是以人民币计的累计盈亏差额。点图上任一交易日、排名按钮或交易日下拉框，可看四只 ETF 的价格贡献、分红、佣金、滑点，以及两个账户各自的当天盈亏。差额方向可切换，也可检查其他自定义组合的一年、两年窗口。

每个交易日的 B 减 A 等于 B 当日权益变动减 A 当日权益变动。累计值等于截至当日两账户盈亏之差。按有符号的每日变化将正、负方向分别排出前三，不足三天按实际天数，并列取较早交易日。差额为负时，“增加”表示 B 追近 A。首日和零变动日均不参与排名。使用十进制逐日核对四项与四只 ETF 的合计，并将各只 ETF 的各项每日贡献累加，与整期结果逐项核对。

### Agent

继续使用 `GET /api/v1/backtest/overlay` 的六个查询参数或相同参数的 CLI。所有有效方向均在 `attribution.dailyGaps` 下，例如 `["B-A"]`。`days` 按交易日升序，每行包含 `date`、两账户当日盈亏 `targetChange/referenceChange`、当日差额 `change`、累计差额 `cumulative`、逐只 `byEtf` 及合计 `totals`。`increases` 和 `decreases` 按变动幅度给出日期，可用该日期在 `days` 中找明细。金额按十进制字符串输出。

```sh
python scripts/interactive_backtest.py --overlay --start 2025-10-29 --end 2026-10-29 --capital 100000 --rebalance monthly --fees base --weights '1,1,1,3|3,1,0,6|1,0,0,1' > overlay.json
jq '.attribution.dailyGaps["B-A"] | {increases,decreases,day:(.days[] | select(.date=="2026-06-25"))}' overlay.json
```
