## 先看结论

基准费用下，23轮股票持仓全部已经结束，其中10轮只持有1～5个正持仓收盘，股票腿合计亏8,719.78元；这10轮在零费用重新模拟下仍亏7,819.50元。短持有亏损不全由交易费造成。不过持有多久是事后结果，不能由此推导“强制持有超过5日”就能改善收益。

两年1362个起点中，基准ADX落后纯债616次。按实际成交量加回ADX相对纯债多付的佣金和滑点后，295次转正，321次仍落后。独立零费用重跑仍有331次落后，数量不同来自现金、整手、资本和执行路径变化，不能混为同一组窗口或因果归因。

完整默认区间基准ADX相对纯债多赚5,656.94元，高费用则少赚538.90元。模型优势对费用敏感，尚不能认定稳定优于纯债；本轮不选最优费用替代原结果。

## 看板怎么用

打开 `backtest.html#adx-trades`（回放区域有“交易体检与费用对比”入口）。输入共用日期和本金，一次运行低、基准、高、零成本四档。默认2019-03-20～2026-10-30、每户10万元。

- 切换一年/两年：同时查看ADX和纯债赚钱、年化≥4%、最差盈亏及费用影响分类。
- 展开不重叠区间：12个预设锚点全部显示，可点开任一期；每期重新从相同现金开始。
- 切换费用查看实际轮次，筛选短持有、未结束或按亏损排序；点“逐日体检”保留原账户资本和持仓，不把该轮重新从10万元开始。
- 明细包括两户净值、区间回撤、累计盈亏差额；点日期核对逐ETF价格、分红、佣金、滑点以及实际模拟订单和前一收盘因子。ADX读数、+DI、−DI同时显示。

## Agent与复现

```sh
PYTHONPATH=src python scripts/adx_trades.py --start 2019-03-20 --end 2026-10-30 --capital 100000 --output NEW-comparison.json
PYTHONPATH=src python scripts/adx_trades.py --detail --fees base --episode 2025-10-10 --output NEW-episode.json
PYTHONPATH=src python scripts/adx_trades.py --detail --start 2021-02-10 --end 2023-02-10 --fees high --output NEW-window.json
```

- `GET /api/v1/backtest/adx-trades?start=2019-03-20&end=2026-10-30&capital=100000`：四费用汇总、轮次和全部非重叠链；2967逐日起点的完整矩阵在归档comparison.json/CLI中，API省略重复大矩阵。
- `GET /api/v1/backtest/adx-trade-detail?start=2019-03-20&end=2026-10-30&capital=100000&fees=base&episode=2025-10-10`：沿用原连续账户，选择实际入场日。
- 同接口不传episode：从指定start/end重新建现金账户，供满期窗口对照。错误参数返回400、证据不完整或对账失败返回503。默认归档使用SHA256校验，CLI拒绝覆盖文件。

后续应先审阅失败交易和费用影响，再决定是否另立确认天数/分档仓位实验。不能把持有期事后分组直接当作有效新策略，也不能把本轮数据冒称未见样本。
