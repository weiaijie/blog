## 如何复核

在项目目录运行：

```sh
python scripts/interactive_backtest.py --overlay --start 2025-10-29 --end 2026-10-29 --capital 100000 --fees base --rebalance monthly --weights '1,1,1,3|3,1,0,6|1,0,0,1'
```

看板「同区间数据 JSON」与 Agent 的 `GET /api/v1/backtest/overlay` 接受同样的 start、end、capital、fees、rebalance、weights。读取 `attribution.holding.differences["B-A"]` 或 `attribution.peakToTrough.A.differences["B-A"]`，其中 `byEtf` 是逐只 ETF 的明细，`totals` 是各列合计，`accountChange` 是独立取自两组账户盈亏的差额。同区间 `accounts.A` 等字段还提供账户起止权益与自身明细。选择其他峰谷时用相应组合键。某组合全程无收盘回撤时其峰谷字段为 null。

- 在整个持有期起点以现金开始。峰谷区间沿用当时的实际模拟持仓和分红应收，统计前高收盘后至谷底收盘的变化。
- 每只 ETF 的每日价格贡献等于此前持仓乘以隔夜价差，加上开盘交易后持仓乘以当日开盘到收盘的价差。
- 分红按登记日持仓在除息日计入应收。到账只是应收转为现金。佣金取模拟成交费用，滑点按买卖方向计入模拟成交价与当日开盘价的差额。
- 使用十进制金额逐日核对账户权益。四项之和、各 ETF 之和、账户权益变化和两账户盈亏之差都必须相等。独立测试用收盘持仓市值变动减去按开盘价计算的交易净流入复算价格贡献，并从成交重建登记日份额。
