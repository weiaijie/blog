## 复现

标准研究脚本只需Python3标准库。可选浏览器验收额外需要Playwright及Chromium。已有原始快照禁止原地重跑抓取脚本。

```sh
python scripts/verify_project.py
PYTHONPATH=src python -m unittest discover -s tests -v
PYTHONPATH=src python scripts/run_research.py --output /tmp/etf-reproduce
PYTHONPATH=src python scripts/check_execution_results.py --results /tmp/etf-reproduce
python scripts/build_site.py --results /tmp/etf-reproduce --output /tmp/etf-index.html
```

site/index.html及app.js/style.css为静态文件，在项目目录运行 `python -m http.server 8765 --bind 127.0.0.1` 后访问 `/site/`。不必安装交易客户端。
