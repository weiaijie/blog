# 四种投资方式逐日起点比较

工作台的“四种投资方式 · 逐日起点比较”使用 2019-03-20 至 2026-10-30 的共同交易日。每个起点四户各有人民币 100,000 元现金，使用沪深300 ETF（510300）、国债 ETF（511010）及基准费用（佣金万分之三，每笔最低 5 元，单边滑点 5 个基点）。一次建仓与按月三批完成后持有。120 日趋势每月判断，多因子 v1 按前一收盘的三项投票决定是否在下一开盘切换。120 个历史收盘仅供预热，起点前没有持仓和收益。

周年遇休市顺延至下一交易日。按实际历日、365.25 天复利计算年化，期末净盈亏严格大于零才算赚钱。最差按到期净盈亏排序；如并列，取最早起点。相邻窗口共享大量行情，以上次数描述这段历史。

多因子两个持有期最差都从 2021-02-10 开始。第一次切换在 03-08 收盘出现，股债60日相对强弱由满足转为未满足，总票数从 2 降到 1。03-09 开盘模拟卖出 8,600 份沪深300、买入 300 份国债。点任一行“看最差一期”即可浏览四户在同一段行情中的全部调仓日，查看收盘时三个因子的读数、是否满足、哪项改变、计划及模拟成交数量。还可点“逐日回放本期多因子账户”逐日查看未触发的日期。

- [所有窗口的期末权益](entries.csv)和[默认统计](summary.json)可离线读取。原三组共 8,901 个期末额及起止日期逐项与原归档对齐。
- Agent 使用 `GET /api/v1/backtest/method-windows?start=2019-03-20&end=2026-10-30&capital=100000&fees=base&installments=3&rebalance=hold`。以对应最差起止日期替换 start/end，再请求 `/api/v1/backtest/method-detail`；多因子的 events 含 decision（当日读数及票数）、previousVotes、changedFactors、plan 和 orders。首次建仓没有前一日账户信号，previousVotes 为空。
- `python scripts/method_windows.py --export new-entries.csv` 从模拟引擎重新生成四组期末额。`python scripts/check_multifactor_windows.py` 另取连续回放的每日目标，在每个起点重新投入本金，按次日开盘和整手限制模拟，并对账所有 2,967 个多因子期末权益。自定义本金和费率时重新模拟各户。
