# 统一量化工作台交付

新增Vue 3 / TypeScript / Vite工程、Vue Router分页面和Element Plus表单操作/详情抽屉，保留Lightweight Charts 5.0.9。生产入口为/workbench/及根路径，旧market.html/backtest.html保留。

## 可操作能力

- 五页导航：研究总览、行情与数据、模型回测、组合比较、研究报告。
- 日期、本金、费用与配比共用方案；本机保存恢复、删除撤销、JSON导入导出、复现链接、Agent请求清单。
- 逐日回放只请求当前前缀，可单步/自动播放/完整区间；K线、成交标记、权益/回撤及当日因子和订单。
- 自定义1至3套配比，以及固定四方法和技术确认模型的一年/两年逐日起点统计；最差期同区间曲线、日期选取、模型因子和交易详情。
- 配比比较按ETF拆整个持有期、所选组合峰谷期和逐日价差/分红/佣金/滑点，展示累计差额及变化最大日期。
- 报告页集中旧固定专题，明确不受当前方案控制。当前进度集中至docs/CURRENT_STATUS.md，旧README/计划/接续已完整归档。

## 验证口径

新旧数值以同一个Python计算层、相同GET参数对照，前端不重新实现收益或交易信号。浏览器测试还直接对照上一部署接口的完整JSON及显示数值。结果一致说明界面迁移没有改动计算，不构成另一个独立执行引擎验证。

详细测试、截图与部署记录见VALIDATION.md及同目录JSON。策略、18户前瞻、原始证据和旧研究报告不因界面交付改变。界面入口仅内网，未部署公网。

## 构建及限制

Windows Node 22.22.0构建；依赖精确版本及npm锁已保存，Ubuntu提供已构建静态资源，运行不依赖Node。源码在frontend，产物在site/workbench。生产仅暴露Vite清单白名单中的资源，不能读取任意路径或源码。

方案只存当前浏览器，不自动云同步；可用JSON/链接跨设备复现。专题报告仍通过旧页访问，不声称所有专题已重写。研究总览只显示18户中的月度50/50基准曲线。无新因子/调参/实盘功能；新规则须另立研究协议。
