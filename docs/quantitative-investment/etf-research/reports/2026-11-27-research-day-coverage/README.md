## 政策证据

- 从中国政府网要闻索引和证监会首页发现符合关键词的公开资料，实际取回索引和文章。覆盖范围仅限这两个来源、给定筛选规则及最多 16 个候选。抓不到、页面结构异常或条数超限均有独立状态。证监会首页同时含有转载和历史栏目链接，本次两次抓取重复发现同一组 10 个 URL。
- 本次发现 11 月 27 日中国政府网转载页面的 `firstpublishedtime` 标注为 12:25:00，证监会转载页面的 `PubDate` 标注为 12:46:39。保留两份原文响应、各自哈希及 16:50 后的实际取回时间，沿用此前对新华社原稿与转载的区分。这 10 个 URL 目前都待审核，不能计入独立事件样本数。[中国政府网页面](https://www.gov.cn/yaowen/liebiao/202611/content_7087445.htm) · [证监会页面](https://www.csrc.gov.cn/csrc/c100028/c7673432/content.shtml)
- 同一 URL 和同一原始响应有稳定取证键；原始响应改变时取证键会改变，早先快照仍可核对。仅凭原始字节变化无法断定政策文本变了。正式事件归并及修订审核仍待接入连续流程。

## 操作与核验

本轮通过 383 项 Python 测试、原份额净值样例复算和项目静态清单核对。另从内容寻址归档恢复两日所需的 210 个证据与代码文件，在新目录重新生成两份覆盖记录并逐字段核对。[恢复演练回执](restore-check.json)

```sh
python scripts/collect_policy_etf_day.py --day 2026-11-27
python scripts/collect_policy_etf_day.py --verify data/snapshots/20261127T085053Z-9ea3f925-policy-etf-day
python scripts/research_day_coverage.py --verify reports/2026-11-27-research-day-coverage/2026-11-27.json
```

日级输入按照独立交易日历取得上一交易日与下一交易日。两只基金用上交所当期清算总份额和同估值日管理人单位净值计算。口径核验复用已封存的币种、份额折算文件，同步取最新交易所公告目录以发现新的折算标题。国债 PCF 要同时核对其交易日和前一估值日。先抓到清算份额或先抓到净值时，缺另一项的估算保留空值。

若要检查信息时点，给覆盖命令传入 `--policy-etf`、`--sse` 与 `--decision-at 2026-11-27T12:25:00+08:00`。试验返回两类证据均未就绪，政策候选数保持未知。测到的实际缺失与决策时尚未可用属于不同状态。正式生产调度、缺日补采与看板覆盖仍待接入。本批为试跑数据，12 个月观察期未起算。
