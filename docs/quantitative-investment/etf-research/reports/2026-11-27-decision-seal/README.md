# 前瞻决策的定时封存

独立研究输入固定在北京时间 08:52 开始组装，08:55 为实际归档核验截止。当天须由核验过的交易日历确认。服务读取留档的量价、政策、ETF 份额净值和沪市两融以及同一期收报时点。使用既有只读行情发布链路，产物保存到独立研究目录。

封存记录包括开始、计算完成和归档核验时间，源证据引用、特征就绪时间、政策及资金字段缺口、预登记协议与实现哈希。只有系统计划触发、本次输入在截止前实际归档、独立研究已经起算且量价基线完整时，才标记为可供后续训练使用的前瞻输入。各增量版的输入覆盖单列。错过截止、起点未定和字段缺失使用各自状态。正式样本还需五个交易日的标签按时完结核验，模型预测与评价另行留档。

## 操作与复验

- 例行服务为 `etf-research-decision.timer` 与 `etf-research-decision.service`。查看用户级 systemd 的下一次触发与执行日志。
- 决策回执位于独立研究目录 `reports/research-decisions/<交易日>/<调用标识>/receipt.json`。缺回执的尝试不能计入样本。单次诊断使用 `--probe YYYY-MM-DD`，单独落在 `reports/research-decision-probes`。
- 对已有归档，在对应版本的 Python 环境使用 `PYTHONPATH=src python scripts/seal_observation_decision.py --verify <回执所在目录> --observation-root <独立研究目录> --archive-store <独立归档存储>`。回执的归档哈希可用于现有内容寻址恢复流程，恢复目录用同一封存命令重验。
- GitHub 复验可用表内归档清单逐项核对当前提交对应文件的字节数和 SHA256。其中 `decision.json` 绑定协议、输入 SHA256、时钟和各版覆盖，`records/manifest.json` 与回执绑定内容归档。传输须保留封存文件原字节。
