# 策略中心

入口为工作台侧栏「策略中心」或 `/workbench/#/catalog`。收录 7 个境内模型、4 组跨市场基准。输入模型名、因子或报告标题，可以查看规则、源代码、相关研究和同一数据版本的一年、两年统计。选择「用报告参数回放」会载入该条目的日期、配比、本金、费用和模型。固定配比基准使用月度再平衡，境内一次建仓使用持有模式。

人工和 Agent 共读 `GET /strategy-catalog.json`。条目以唯一 id 标识，包含可直接载入工作台的 plan、来源提交和报告链接（来源提交在台账顶层），以及各期限的满期、赚钱、年化达标和最差到期盈亏。境内和跨市场样本起点分别为 2019-03-20 和 2022-03-30，数据截至 2026-11-12。相邻交易日起点的窗口共享大部分行情。

`python scripts/build_strategy_catalog.py` 从固定 SHA256 的版本对比报告提取数据。Vue 页面复用工作台的方案解析和回放请求生成逻辑。桌面 1366 像素与手机 390 像素分别用 ADX、标普基准检查了空搜索、筛选、详情、参数恢复和首日回放。后续可在台账上增加因子、版本与研究证据的二维关系图。
