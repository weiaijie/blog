# 18 户前瞻模拟按发布时点回看

工作台总览的「18 户前瞻模拟」可输入北京时间回看。Agent 用同一接口的 asOf 查询，结果含估值日、查询时点、实际发布完成时间、运行类型、回执与检查点的校验身份。核验时对照发布前后的指针、日报清单和冻结检查点。省略 asOf 时沿用最新账户查询。

11 月 24–26 日的日报是在 27 日补发。每次估值继续使用冻结账户的原始账本，从实际完成回执才可查到该日数据。只有未绑定正式发布指针的旧验证文件时，历史请求返回暂无可核验的发布回执。11 月 6 日可归档重算的初期检查点仍可用作指定文件核对。 [三天补发记录](../2026-11-27-admission/README.md) · [27 日正式发布](../2026-11-27-forward-publication/README.md)

历史接口：GET /api/v1/research/forward-milestones?asOf=2026-11-27T17%3A00%3A00%2B08%3A00。查询必须带时区。命令行也可固定单个检查点并指定核验时点，实际尚未发布时返回错误。首页查询、正式 6、12、24 个月的复盘口径和独立研究准入继续按各自的回执核算。

```bash
export PYTHONPATH=src
python scripts/forward_milestones.py --observed-at 2026-11-27T17:00:00+08:00
python scripts/forward_milestones.py --checkpoint reports/daily/20261127T170315-58f85234/forward_checkpoint.json --observed-at 2026-11-27T17:03:27+08:00
python -m unittest discover -s tests -p test_forward_milestones.py -v
```
