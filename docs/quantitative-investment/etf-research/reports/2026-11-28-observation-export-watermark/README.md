# 夜间证据导出水位保护

导出器在成功发布批次后，另存一份内容完全相同的批次回执。历史检查将每份已登记回执与批次目录及清单对应。若丢失最新一批或连续多批，检查会列出缺失的批次编号，定时导出保留失败记录和之前成功的水位。恢复原批次并逐项验证后才可接续。登记是追加的，旧批次和原始回执保留。

已存在的批次须先通过全链内容核验再补登记。正常定时导出可处理发布完成、登记尚未写入的中断。对原有部署，也可在相同参数下将 `--run` 换成 `--register-published`，只核验并登记已有批次。使用 `--audit` 查看全链核验数和 `registeredBatchCount`。
