# 在一套组合的最差持有期内重放所有组合

在看板填两至三套配比，运行并排比较，然后点击任一组合一年或两年表格中的「同区间对比」。所选组合的最差到期盈亏确定这次的起止日期，期内所有组合按同一本金从现金起步，保留各自配比和原比较共用的费用、调仓方式。相同到期盈亏并列时取最早的满期起点。区间内没有满期样本时，同区间入口为空。

一张图共用交易日轴。上半图按初始本金将各组净值归一至 1，下半图画相对该组区间内此前最高收盘总资产的回撤。悬停或触摸日期可同时读取各组净值和回撤。表中列出到期盈亏、最大收盘回撤、相应的前高和谷底、首次收复前高日期以及从前高到恢复的交易日数。

「最早收复前高」按各组自身最大回撤首次收复的日历日期比较。各组的前高可能发生在不同日。零回撤显示「无回撤」，期末未恢复显示「期末未收复」，两者均不参与最早日期排名。到期盈亏最高、回撤最浅以及恢复日期并列时保留全部并列组合。

### 可复核示例

10 万元、基准费用、每月调仓，全样本 2023-10-30 至 2026-10-30。四项配比依次为沪深300、标普500、恒生、国债。选择 A 的一年最差一期，所有组合均回放 2025-10-29 至 2026-10-29。

| 组合 | 配比 | 到期盈亏（元） | 最大收盘回撤 | 前高日期 | 恢复日期 |
|---|---|---:|---:|---|---|
| A | 1/1/1/3 | −2,735.21 | −5.40% | 2026-01-29 | 2026-05-07 |
| B | 3/1/0/6 | −1,800.08 | −5.39% | 2026-06-22 | 期末未收复 |
| C | 1/0/0/1 | −5,629.98 | −9.70% | 2026-06-22 | 期末未收复 |

### Agent 调用

调用[并排比较接口](../2026-11-08-compare-windows/README.md)，按组合和期限读取 `overlays["A"]["1"]` 等参数对象，将六个字段直接作为查询参数传给 `GET /api/v1/backtest/overlay`。已知回放区间时也可以直接运行。接口在 `GET /api/v1/backtest/options` 中登记。

```sh
curl --fail-with-body 'http://10.1.1.120:18766/api/v1/backtest/overlay?start=2025-10-29&end=2026-10-29&capital=100000&fees=base&rebalance=monthly&weights=1,1,1,3%7C3,1,0,6%7C1,0,0,1'
python scripts/interactive_backtest.py --overlay --start 2025-10-29 --end 2026-10-29 --capital 100000 --fees base --rebalance monthly --weights '1,1,1,3|3,1,0,6|1,0,0,1'
```

`portfolios[].daily` 提供日期、人民币总资产、归一化净值和小数形式的回撤，`summary` 提供盈亏及峰谷恢复数据。`recoveryState` 区分 recovered、unrecovered 和 no_drawdown。对于零回撤，底层 summary 沿用已有的起点占位值，恢复展示与排名以 recoveryState 为准。`leaders` 返回到期盈亏最高、回撤最浅、最早收复的组合 ID 列表。
