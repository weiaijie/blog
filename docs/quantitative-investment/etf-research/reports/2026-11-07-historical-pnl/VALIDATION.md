# 历史净收益归因验收

2026-11-07 在独立 Ubuntu 的隔离工作副本上核验，起点提交为 `258e586c6c5b0072f3aef75c1387f40d39578c61`。固定历史覆盖 2018-09-14 至 2026-10-30。

| 检查 | 结果 |
|---|---|
| 输入完整性 | 起点 41 个来源清单、673 个来源文件、1,904 个固定文件通过 SHA256 校验。长历史加载器再次核对日历、未复权 OHLC 及官方分红原文 |
| 模型成交 | 162 场景共 6,674 笔，原冻结诊断逐场景超界计数全部一致。独立脚本直接读取上交所日线，对比高低价、方向、份额、费用、距最近边界的价差与金额 |
| 每日对账 | 18 个账户各 1,967 日，共 35,406 行。登记日持仓推算应收与实收分红，逐日核对现金、应收和净值，用第二套公式复算七项金额 |
| 金额复核口径 | 首次计算使用隔夜与日内持仓，独立复算使用昨日持仓的收盘至收盘损益及当日净交易的开盘至收盘损益。两者共享封存行情和原账本，金额以 Decimal 精确比较 |
| 离线复现 | 两个CSV、JSON摘要及研究报告逐字节一致。原640/1167/1967日研究、两日前瞻、目标、看板及上一轮持有期研究亦通过原有复现命令 |
| 基础测试 | 214 项通过，包含调仓日的隔夜跳空及分红、恰好处于日线边界的成交、卖出超界与收盘峰谷划分 |

复核命令、输入摘要和逐笔明细见[研究报告](PROGRESS.md)。日线能够界定观测价格范围，成交数量和队列仍缺逐笔证据。新结果仅用于历史模拟的解释。
