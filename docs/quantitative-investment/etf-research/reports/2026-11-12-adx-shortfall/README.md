# 321个加回费用后仍落后纯债的两年窗口

固定上轮清单，逐窗重放ADX、同日起点只持国债、一次建仓股债各半，并检查事后取消短空档换仓。[预先固定口径](PROTOCOL.md) · [全部321行](cohort.json)。日期、本金、费用、信号和原账户均不变，不把本轮结果当成新策略。

## 结论

- 248个窗口的股票价差＋确权分红合计为负。另73个股票部分虽为正，但赚到的金额不足以弥补比纯债少获得的国债收益；321个窗口的国债贡献差均为负。
- 320个窗口在卖出后的上涨日存在股票少赚，但同时也有下跌日少亏。这是与股债各半的机会成本对照，不能再加到相对纯债的亏损里；纯债本身也不持股票。
- 270个窗口出现清仓后≤5个交易日重买，但只重复覆盖两个实际事件：2022-07-18卖出/07-21重买（226窗），2024-11-26卖出/12-02重买（44窗）。51窗没有这种短空档。
- 使用事后重买日期取消这两个短空档，270窗价格/分红路径有所改善、51窗不变；但仍有277窗加回额外费用后落后纯债，计入费用时321窗仍全部落后。不能用这两段已观察事件证明“少换仓”是一条稳定盈利规则。

起点年份为2020年4窗、2021年184窗、2022年93窗、2023年39窗、2024年1窗。窗口高度重叠，以上是历史样本内计数，不是独立发生次数或未来概率；三个视角标签不互斥。

另外，与股债各半比较，卖出后的429个完整无股票日中，上涨日股票贡献差-69,273.00元，下跌日+77,941.80元，两者抵消后为+8,668.80元；加国债替代贡献+1,899.60元，该组日期合计+10,568.40元。其他日期-1,028.99元，全期相对股债各半+9,539.41元。这说明不能只挑上涨日声称错过69,273元，也不能把逐日大额累积当作实际投资亏损。

## 看板与Agent

入口 `backtest.html#adx-shortfall`，回放区域有“321个落后窗口拆解”链接。点击案例或全部窗口列表，可以查：

- 相对纯债的六项账目；每轮股票买入、卖出或期末、持有天数、价格和分红贡献。
- 与股债各半比较的错过上涨、避开下跌、国债替代及其余日期贡献，完整对账。
- 实际清仓/重买日期及事后取消的目标批次，价格/分红路径变化与费用节省分开；没有短空档时明确显示未修改任何批次。
- 原ADX与纯债净值、回撤、累计净差额和加回费用差额。点图、选择日期或点“看买入/卖出/清仓/重买”，核对前一收盘因子、翻票、份额、订单、佣金、滑点和执行限制。
- 事后诊断订单与原订单分开显示，API还提供诊断净值和逐日完整归因，不把诊断账户混成原策略曲线。

```sh
PYTHONPATH=src python scripts/adx_shortfall.py --output NEW-cohort.json
PYTHONPATH=src python scripts/adx_shortfall.py --start 2021-02-10 --output NEW-case.json
```

- `GET /api/v1/backtest/adx-shortfall`：固定10万元/基准费用的321个窗口及所有汇总。
- `GET /api/v1/backtest/adx-shortfall-detail?start=2021-02-10`：该固定起点对应的两年满期、因子、实际订单、三个视角和反事实诊断明细。
- 接口不允许悄悄更换本金、费用、期限而仍套321窗结果；未知参数或不在清单中的起点返回400，来源哈希或对账失败返回503。CLI独占创建输出文件，不覆盖旧报告。

`netGap`是原净差额；`grossGap`是原成交量下加回额外费用的差额，仍包含费用对持仓路径的历史影响，不是零成本重跑。`opportunity`使用股债各半基准；`churn`为使用未来重买日期的事后取消实验，三者不相加。`counterfactual.daily`逐日差额以原ADX为基准，`replay.daily`以纯债为基准。
