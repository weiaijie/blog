# WordPress 插件发布自检清单

代码与安全
- 遵循 WP Coding Standards；所有输入均 sanitize，输出均 escape。
- 使用 Nonce/权限检查；禁用直接访问 PHP 文件。
- 国际化 i18n（__、_e 等）；文本可翻译；域名统一。

结构与卸载
- 插件主文件头信息完整；
- 含卸载脚本（uninstall.php），删除选项/自定义表。

兼容与性能
- 兼容最近 3 个 WP 主版本与常见主题/缓存；
- 大数据量下的性能基准（例如 1k 变体表格 < 1.2s）。

发布与分发
- WordPress.org 的 Readme 与截图、常见问题；
- 站内销售使用 Freemius/Lemon Squeezy（许可/自动更新/税务）。

隐私与数据
- 最小化采集；远程校验温和且不锁核心功能；
- 记录数据处理与隐私说明。

文档与支持
- 安装指南、使用教程、FAQ、支持渠道与 SLA；
- 变更日志（Changelog）清晰。

通过标准
- 核心流程无崩溃；无安全红线；审核问题可 48 小时内修正。
