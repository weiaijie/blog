# Shopify App 上架自检清单（合规优先）

功能与权限
- 仅申请必要 OAuth Scope；权限说明清晰。
- 安装/卸载流程顺畅；卸载即删除店铺数据或提供自助删除。
- 计费：使用 Billing API（订阅/Usage），清晰标注试用期与费用。

体验与质量
- 嵌入式 UI：App Bridge + Polaris；导航一致；空状态/错误态明确。
- 性能：首屏加载合理；错误日志与监控。
- 多语言与时区处理正确。

合规与文档
- 隐私政策与数据处理说明（PII 存储/加密/保留时间）。
- 卸载 Webhook 与数据删除路径验证。
- 审核演示视频：安装→授权→核心流程→计费→卸载。
- 应用商店素材：截图/视频/价值点/对比/FAQ。

技术注意
- 如果使用 MySQL：必须使用 utf8mb4 编码，避免中文变“?”。
- API 限流与重试策略；错误兜底。

通过标准
- 审核问题可复现且能在 48 小时内修复；零高危权限与隐私风险。
