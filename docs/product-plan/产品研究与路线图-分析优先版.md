# 产品研究与路线图（分析优先版）

目的
- 以“先分析、后决策”为原则，系统性验证痛点→定义方案→小步交付→度量复盘。
- 本文档集合：调研计划、模板、评分框架、路线图（含 Gate）、日志与指标看板。

原则
- 不预设结论；任何路线需有证据（访谈/数据/竞品差评）。
- 决策可回滚：每次变更进入决策日志，附理由与影响评估。
- 小步快跑：每 1–2 周一个可验证的产出（MVP/改版/内容）。
- 安全与合规优先：上架与隐私检查前置。

使用方法
- 第 1 周：按 研究计划.md 启动；把数据填入模板（竞品表/访谈纪要）。
- 每周五：更新决策日志；用 机会点评分框架.md 打分并决定是否通过 Gate。
- 每次上架/发布前：走对应检查清单逐项自检。
- 数据：按 指标看板.md 建立漏斗与使用指标，周会复盘。

产出验收（示例）
- 研究阶段：≥15 次访谈、≥30 条“高痛感”证据；形成 1–2 个候选痛点并打分。
- MVP 阶段：定义明确场景+成功标准；有真实用户试用与反馈。
- 增长阶段：内容/渠道与实验有记录可复制。

说明
- 这里的示例痛点与路线仅为“占位”，一切以实际调研为准。
