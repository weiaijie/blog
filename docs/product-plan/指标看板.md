# 指标看板（每周复盘）

漏斗（分 WP/Shopify）
- 展示→安装/试用→核心动作完成→付费（各环节转化率）。
- 安装质量：试用留存 7 日/14 日；卸载原因分类。

使用与价值
- 活跃站点数；关键动作完成率（如多行下单、CSV 导入）。
- 任务时间对比（安装前→安装后）。

营收与健康
- MRR、一次性销售、退款率、客单价、LTV；
- 支持：响应/修复时长、CSAT/NPS。

流量与内容
- SEO 自然流量、关键词排名、教程/案例阅读→安装转化率。

数据来源与口径
- 产品埋点（匿名/合规）、WordPress.org/Shopify 后台、支付平台、客服系统。
- 指标定义要唯一口径，并记录到决策/实验对应项中。

目标设定（示例，可调整）
- 研究期：证据样本≥30；
- MVP 期：试用 5–10 家真实站点，完成率≥70%；
- 付费期：站内转化≥2.5% 或 MRR≥$1,000；退款率<5%。
