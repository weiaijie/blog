# 机会点评分框架（Evidence-based）

评分维度与权重（1–5 分）
- 痛感强度（30%）：1=偶发无痛；5=高频高损失（时间/钱/错单）。
- 付费意愿（25%）：1=免费即可；5=明确愿付并给出价格锚。
- 实现难度（15%，反向）：1=极难；5=较易（现成 API/方案）。
- 竞品饱和度（15%，反向）：1=红海头部强；5=差评多/空白。
- 可服务市场/扩展性（15%）：1=小众窄用；5=横向拓展性强。

综合得分公式
- Score = 0.30*Pain + 0.25*WTP + 0.15*Ease + 0.15*White + 0.15*TAM
- 评分必须附证据链接（评论/访谈原话/数据快照）。

决策与 Gate
- Go：Score ≥ 3.6 且“痛感≥4 & 付费≥4”；
- Hold：3.2–3.6，补访谈/补数据后再议；
- No-Go：<3.2 或证据不足。

使用说明
- 每个候选点至少采样 10+ 条证据；避免单一来源偏差。
- 评审会输出：选定 1–2 个方向 + 其 MVP 假设与成功标准。
