# 03 技能任务

## 3.1 前端技能

- [ ] 建立技能矩阵（HTML/CSS/JS/TS/框架/响应式/可访问性）。
- [ ] 每项技能补充项目证据或示例。
- [ ] 统一熟练度分级标准（如 1-5）。
- [ ] 增加“近期使用”标签。

产出物：
- 前端技能卡片或技能矩阵。

验收标准：
- 每项技能至少有一个证明点。

## 3.2 后端技能

- [ ] 仅保留实际使用过的后端技术项。
- [ ] 补充 API 设计与鉴权实践案例。
- [ ] 补充数据库使用与优化实践。
- [ ] 补充部署与运维实践范围。

产出物：
- 后端技能模块。

验收标准：
- 无“只听过未实操”的技术声明。

## 3.3 其他技术能力

- [ ] 补充 Git 工作流与 Code Review 实践。
- [ ] 补充 CI/CD 与自动化场景。
- [ ] 补充云服务实际使用边界。
- [ ] 补充性能优化与安全实践清单。

产出物：
- 其他技术能力模块。

验收标准：
- 性能与安全条目包含具体行动，不只概念。

## 3.4 软技能

- [ ] 补充项目管理方式（计划/风险/进度同步）。
- [ ] 补充团队协作方式与贡献角色。
- [ ] 补充沟通能力案例。
- [ ] 补充排障与问题解决案例。

产出物：
- 软技能模块。

验收标准：
- 每个软技能至少包含一个实际场景。
