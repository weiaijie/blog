# 05 博客任务（V2）

## V2 边界

- [ ] 坚持静态优先（构建期生成页面）。
- [ ] 评论与统计使用托管服务。
- [ ] V2 不自建账号系统/CMS/数据库。

产出物：
- V2 边界说明文档。

验收标准：
- 博客任务全部符合静态优先规则。

## 5.1 博客首页

- [ ] 实现文章列表布局（网格或列表）。
- [ ] 实现分页。
- [ ] 实现侧栏（分类/标签/热门）。
- [ ] 实现搜索（客户端索引或构建期索引）。
- [ ] 实现文章预览字段（封面/标题/摘要/日期/阅读时长/标签）。

产出物：
- 博客首页。

验收标准：
- 在 50+ 篇文章场景下搜索与分页可用。

## 5.2 分类与标签策略

- [ ] 定义分类体系与命名规则。
- [ ] 定义标签规则（格式/数量上限/去重）。
- [ ] 制定 4 类内容的初始选题计划。

产出物：
- 分类与标签规范文档。

验收标准：
- 分类边界清晰且不重叠。

## 5.3 文章详情页

- [ ] 实现文章头部信息区。
- [ ] 实现 Markdown 渲染与标题层级。
- [ ] 实现代码高亮与复制按钮。
- [ ] 实现响应式图片与可选放大预览。
- [ ] 实现自动目录（TOC）。
- [ ] 实现上一篇/下一篇导航。
- [ ] 实现相关文章推荐。
- [ ] 集成托管评论（Giscus 或 Disqus）。

产出物：
- 博客详情页模板。

验收标准：
- 移动端代码块和目录可用。

## 5.4 发布与数据分析

- [ ] 定义 Git + Markdown 发布流程。
- [ ] 定义 front matter 字段规范。
- [ ] 定义发布前检查清单。
- [ ] 配置统计平台（GA 或 Plausible）。
- [ ] 定义月度内容复盘机制。

产出物：
- 内容发布指南。
- 统计配置说明。

验收标准：
- 一篇草稿可按标准流程发布到生产。
