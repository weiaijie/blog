# 06 联系方式任务

## 6.1 联系页布局

- [ ] 实现页面引导文案，明确合作/交流范围。
- [ ] 实现联系方式展示区（图标 + 简述）。
- [ ] 添加时区与可联系时间段。
- [ ] 可选：仅展示城市级位置信息。

产出物：
- 联系页布局。

验收标准：
- 首屏能清晰看到联系入口。

## 6.2 联系表单

- [ ] 定义字段：姓名、邮箱、主题、内容（可选电话/公司）。
- [ ] 实现前端校验与错误提示。
- [ ] 接入托管表单服务（Formspree/EmailJS 等）。
- [ ] 增加防垃圾机制（蜜罐/验证码/限流能力）。
- [ ] 实现提交成功与失败反馈。
- [ ] 条件允许时实现自动回复。

产出物：
- 可用于生产的联系表单。

验收标准：
- 表单提交稳定，错误提示可理解。

## 6.3 其他联系方式

- [ ] 校验社交链接有效性与命名一致性。
- [ ] 可选增加即时通讯渠道并标注使用边界。
- [ ] 可选增加预约工具链接（Calendly 等）。

产出物：
- 其他联系渠道模块。

验收标准：
- 无失效链接。

## 6.4 FAQ 与响应承诺

- [ ] 增加 FAQ：合作范围、流程、周期、费用模型。
- [ ] 增加响应时效承诺（如工作日 24-48 小时）。
- [ ] 增加节假日与繁忙期说明。

产出物：
- FAQ 模块。

验收标准：
- 用户提交前能看到响应预期。

## 6.5 隐私与合规

- [ ] 在提交按钮附近提供隐私说明入口。
- [ ] 明确第三方服务名称与数据流向。
- [ ] 明确保留周期（默认 180 天）。
- [ ] 提供删除请求渠道。
- [ ] 确保 HTTPS 与相关账号 2FA。

产出物：
- 隐私说明页面/模块。

验收标准：
- 数据用途与保留策略明确可见。
