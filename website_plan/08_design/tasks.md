# 08 设计任务

## 8.1 配色系统

- [ ] 确定主色及语义色阶（至少 5 档）。
- [ ] 确定强调色及使用规则。
- [ ] 确定中性色（文本/背景/边框）。
- [ ] 校验关键文本与按钮状态对比度。
- [ ] 定义 CSS 变量命名规范。

产出物：
- 色彩令牌表。
- CSS 变量映射。

验收标准：
- 核心 UI 状态通过可访问性对比要求。

## 8.2 排版系统

- [ ] 选择标题/正文字体/代码字体。
- [ ] 定义字号比例与响应式字体规则。
- [ ] 定义行高与字距规则。
- [ ] 定义链接/引用/代码/列表排版样式。
- [ ] 定义字体加载策略与回退方案。

产出物：
- 排版规范页。

验收标准：
- V1 页面排版风格一致。

## 8.3 视觉素材与动效

- [ ] 准备 Logo 多版本与 favicon。
- [ ] 统一图标风格。
- [ ] 定义插图与项目截图展示规范。
- [ ] 定义图片优化策略（格式/尺寸/响应式加载）。
- [ ] 定义动效策略（过渡/滚动显现/悬停反馈）。
- [ ] 支持减少动画偏好（reduced motion）。

产出物：
- 视觉素材清单。
- 动效规范文档。

验收标准：
- 动效流畅且不影响可用性。

## 8.4 UI 组件规范

- [ ] 定义组件清单（导航/按钮/卡片/表单/弹窗/提示）。
- [ ] 定义组件状态（默认/悬停/激活/禁用/错误）。
- [ ] 定义间距/圆角/阴影令牌。
- [ ] 建立组件示例页（Playground）。
- [ ] 补充组件使用约束，避免样式漂移。

产出物：
- UI 组件规范。

验收标准：
- V1 页面优先复用标准组件，无临时样式拼接。
