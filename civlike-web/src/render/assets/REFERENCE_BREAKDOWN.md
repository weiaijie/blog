# 参考图拆解清单

本文件把当前参考图拆成可执行的资产生产要求。参考图只用于风格、结构和验收，不直接作为贴图或最终模型。

## 一、地形结构细节参考

对应参考图主题：地形结构细节、高度分层、侧面结构、悬崖/坡面变体、顶面细节。

吸收规则：

- 每个地块必须有 `顶面地表`、`覆盖层`、`形体层`、`基岩层`、`底座层`，不能只有一个平面。
- 高度序列至少支持：平地、缓坡、丘陵、山地、高山；雪山是后续变体，不进第一轮。
- 侧面材质要分层：表层土壤、淤泥层、沉积层、岩层、基岩。侧面不能是一整块单色墙。
- 丘陵和山地要有坡型变体：垂直悬崖、阶梯悬崖、破碎悬崖、海蚀悬崖、缓坡草地、碎石坡面。
- 顶面细节用小草、花丛、灌木、小树、岩石、泥地、树桩、苔藓、积雪等模块散布。

落地到第一轮：

- `terrain-hill` 必须先实现顶面、坡面、岩面、坡脚、侧面分层。
- `terrain-water` 必须有低洼水盆和侧壁，不再使用单层水面。
- 暂不做高山、雪山、熔岩地块，但保留高度层级规范。

## 二、资源与改良细节参考

对应参考图主题：资源摆放、资源叠加层级、改良建筑、资源 + 地形组合、特殊资源说明。

吸收规则：

- 资源不改变地形模型本体，作为可叠加装饰层或插槽对象。
- 改良建筑也不改变地形类型，只在资源或地形上叠加，例如农田、牧场、矿场、采石场、渔船、伐木场。
- 每个资源需要有基础地形适配规则：例如小麦适合平原/河流平原，鱼类适合海岸/内陆湖，铁矿适合丘陵/山脉。
- 资源、改良和地形组合后仍要保持地块类型可读，不能让资源盖住地貌。
- 图标和产出数字属于 UI 层，不写入地形资产。

落地顺序：

1. 第一轮不做资源模型，避免分散水域/岸线/丘陵目标。
2. `terrain-water` 和 `transition-shoreline` 制作时预留 `fish_boat_slot` 或 `coast_prop_slot`。
3. `terrain-hill` 制作时预留 `mine_slot`、`stone_slot`、`ore_slot`，但不放最终资源。

## 三、边缘过渡与连接参考

对应参考图主题：边缘过渡、道路连接、河流边缘、海岸边缘、拼接逻辑、边界可读性。

吸收规则：

- 边缘过渡不是装饰贴片，而是系统性资产：草原到沙漠、草原到森林、陆地到海岸、平地到丘陵、丘陵到山地、草原到雪地。
- 岸线分为沙滩海岸、岩石海岸、悬崖海岸、浅水湖泊、港湾/码头等变体。
- 河流边缘要区分标准河岸、浅滩过渡、河口入海、瀑布落差。
- 道路连接需要直线、三岔、四岔、桥梁、穿山隧道等规则，但这属于后续交通层。
- 所有边缘连接要基于六边形边，不允许只适配单一截图角度。

落地到第一轮：

- `transition-shoreline` 必须是可沿 hex 边旋转复用的资产。
- 第一版只做“沙滩海岸 + 浅滩 + 泡沫线”，岩石海岸和港湾后续再做。
- 水陆组合验收时至少使用 3 个方向旋转测试。

## 四、光照与氛围细节参考

对应参考图主题：清晨、正午、黄昏、夜晚、薄雾、风格对比、材质与植被。

吸收规则：

- 模型本身使用中性材质，不为清晨/黄昏/夜晚单独烘死颜色。
- 光照预设后续在 `visual-lab` 中统一做：清晨、正午、黄昏、夜晚、薄雾。
- 风格目标选择“半写实策略风 + 高可读性”，不是纯 low-poly，也不是写实大世界。
- 地表材质必须有草地、干土、沙地、雪地、裸岩、浅海、深水等基础族群。
- 植被要区分草地、灌木、阔叶林、针叶林、热带植被、稀树草原、棕榈树等，但不在第一轮展开。
- 水体和海岸要特别重视反射、浅滩、湿地、泡沫和岩石边缘。

落地到第一轮：

- `terrain-water` 材质命名要支持未来水面动画和光照预设。
- `transition-shoreline` 使用中性浅滩/泡沫材质，后续由灯光改变氛围。
- `terrain-hill` 的岩面、草坡、土坡材质必须分开，便于后续光照与 AO。

## 五、第一批验收画面

第一批真实资产进入 `visual-lab` 后，必须组出一个小场景：

```text
草地   丘陵   草地
水域   岸线   草地
水域   岸线   丘陵
```

验收重点：

- 远看能分清水、岸线、丘陵和草地。
- 近看能看出顶面细节和侧面分层。
- 水陆交界有浅滩和泡沫，不硬切。
- 丘陵从坡脚自然抬起，不像尖锥插在地块上。
- 地块仍保留六边形逻辑，但视觉边缘更自然。

## 六、暂缓项

以下内容先不做：

- 城市、单位、资源最终模型。
- 道路完整连接系统。
- 河流完整拓扑系统。
- 高山、雪山、熔岩地块。
- 清晨/正午/黄昏/夜晚完整灯光切换。

原因：地形底座、岸线和高度层级没成立前，其他内容都会显得漂浮或堆砌。
