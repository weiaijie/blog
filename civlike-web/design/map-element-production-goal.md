# 地图资产持续制作目标

## 目标与计数

至少 100 个独立资产，当前规划 108 项。唯一清单为 `src/render/assets/mapElementRoadmap.ts`，页面“资产进度”直接使用此清单。只有 `elements/manifest.json` 中存在可加载 GLB 的独立 family 才计入已建模；旧版本、换色、幼体/成熟阶段、参考图片和待制作条目均不另计数。

- 当前：18 类资产、25 个版本。基础模型不等于自然动态验收完成。
- 已有自然风动农田样板：翻耕地、麦田、蔬菜田。
- 物候样板：浆果灌木 V4、苹果树、南瓜地、向日葵。
- 动物成长样板：绵羊 V5、牛、马、鸡；支持分部位成长、行走/采食和有限繁育展示。
- 尚未完成：其余基础模型的生命周期重做、90 项新资产、真实地图种群模拟、建筑施工升级、地图级连接与 LOD。
- 工作约束：每批开始和结束检查 Codex 账户额度。任何可见 Codex 使用窗口剩余不足 2% 时，保存当前证据和进度，调用目标暂停并通知用户；不自动使用额度重置或购买额度。2026-10-12 本批开始读取为剩余 32%。

## 资产协议与质量门槛

- C 风格非写实，保持清晰轮廓、材料区别、实际零件和有节制的不规则变化；不把规则球堆、复制方块数量当精细度。
- 米制、Blender Z-up / 正面 -Y，GLB Y-up；根部、轮轴、桥端和轨道接点明确。
- 每个实际资产有可编辑 `.blend`、`.glb`、清单尺寸/三角面/字节数；新资产无三视设计参考时不挪用别的资产图片冒充。
- 生命周期按器官节点定义：shoot / structure / foliage / bud / blossom / fruit / seed / litter；节点带出现、成形、衰退区间和风动参数。整株根节点不缩放，花朵退去后独立果实出现。
- GLB 保存所有器官和阶段元数据，浏览器负责物候运行；目前并不包含可直接在任意查看器播放的生长剪辑。地图接入必须同时使用生命周期驱动。
- 每批检查生成文件回读、有限坐标、三角面、构建、相关测试，以及浏览器桌面/手机截图、非空像素、取景、阶段变化、暂停和错误日志。
- 当前样板预算 25,000 三角面 / 2.5 MB / 450 次预览绘制调用；这只是单资产上限，不是 200 格性能合格。后续需实例化与远景合并/LOD。
- 动物繁育最初为可控预览状态转换；只有接入模拟、数量上限、出生条件与行为测试之后，才能称为地图种群系统。
- 本地中文提交逐批保存，不默认推送；不改动其他项目未提交文件。

## 第二批：动物成长与繁育样板

- 新增 3 个独立 family：`cow`、`horse`、`chicken`；绵羊升级为 `sheep-v5`，原版保留。
- 使用不同头身比例、腿长和毛羽颜色表现幼体；羊毛、牛角、乳房、马鬃、鸡冠和尾羽按成熟度出现。模型根节点不等比例缩小。
- 双段腿部 IK 配合支撑/摆动相位；行走时略降重心，使腿长能够触及步幅内的脚掌落点。休息、行走、采食/啄食之间平滑混合。
- 繁育为缩时预览：成年后可开启，8 秒后显示子代；哺乳动物最多 1 只，鸡最多 3 只，另展示孵化中的蛋。子代约 45 秒长大，不递归繁殖；暂停冻结等待和子代成长，关闭预览清空这一组。
- 牛的亲代外形区分雌性乳房与无乳房伴侣；鸡冠尺寸作亲代差异。尚未实现完整性别、受孕、遗传、死亡、饥饿或生态条件模型。
- GLB 保存可编辑零件与 `faunaSpecies`、`animalRole`、`youngPosition`、`youngScale`、腿段长度等元数据。成长和行为由 `mapElementAnimals.ts` 驱动，不是内嵌骨骼剪辑；下载后仅靠通用 GLB 查看器不会自动播放。
- 浏览器动物专项检查脚本：`node scripts/verify-map-fauna.mjs`，证据在 `artifacts/map-elements/fauna/`。近景四款在 2,040–4,000 三角面内；仍需地图级 LOD/实例化。
