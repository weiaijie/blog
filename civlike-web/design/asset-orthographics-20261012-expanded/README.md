# 地图元素三视图参考图集

新增 **32 款**，加上[上一组 4 款](../asset-orthographics-20261012/reference-manifest.json)，共 **36 款元素**。延续 C 风格：非写实、清晰切面、低多边形、哑光色块。

## 使用范围

- 静态物件和河鱼：从左到右为正面、侧面、俯视参考。
- 人物和陆生动物：从左到右为正面、侧面、背面参考。
- 下表链接指向当前选用版；带 `-v2` 的为修正版，同目录初稿保留作对照，不计为新增元素。
- 这是三视概念参考，不是精确 CAD 投影、可用 GLB 或已绑定动画的模型。不能保证逐像素的跨视图几何一致。
- 使用内置 image_gen 逐款生成；原始及修正提示词、文件尺寸、SHA256 均保存在[生成清单](reference-manifest.json)。
- 本轮没有修改地图代码，没有把图片当作已完成模型，也没有部署。

## 建模与动画拆分

- 人物保留中立站姿，骨骼控制四肢；工具和货物单独建模挂接，不烘焙进手部。
- 动物拆分躯干、四肢、尾部；河鱼用少量骨骼控制身体和尾鳍，不逐片生成鳞片。
- 树冠、草叶与芦苇按根部到顶部保留摆动权重；果实作为可选实例。
- 船体、船桨、帆、舵分开；车轮以轮轴为枢轴，围栏门以铰链为枢轴。
- 农田作为薄表层与作物实例组合，不建厚重孤岛底座；桥面高度、跨距、道路宽度在 Blender 中按地图单位统一。
- 导出前检查缩放、朝向、底部枢轴、法线、材质数量和 LOD。三视图先校准再建模，不把整张拼图当一个物体送入单图转三维工具。

## 校准提醒

已对 12 款做定向修正，重点是正视倾角、桥梁立柱、船帆横桁、鱼尾投影和车上货物位置。仍需人工确认：

- 芦苇正面为五根，俯视只清楚显示四个穗头；建模按五根补齐空间位置。
- 水井俯视屋脊方向需与正、侧面重新对齐。
- 石桥拱券与纵向坡度以侧面为准，正面只是简化入口参考。
- 各图中的尺寸、枝叶遮挡、花纹和细小五金不是工程测量依据；按统一几何模型修正。
