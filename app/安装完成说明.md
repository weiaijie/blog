            └── NavigationContainer (React Navigation)

                    ├── Auth Stack (未登录)

## 🐛 如果遇到问题

### 问题1：端口3000被占用

**解决方法：**
1. 关闭浏览器中的 http://localhost:3000 标签页
2. 或者修改 `webpack.config.js` 中的端口号
3. 或者在任务管理器中结束占用端口的进程

### 问题2：页面显示错误

**解决方法：**
```bash
# 清理缓存
npm start -- --reset-cache

# 重新运行
npm run web
```

### 问题3：导航不工作

**检查：**
1. 确保所有依赖都已安装
2. 检查浏览器控制台是否有错误
3. 确认使用的是 RNAppNavigator

### 问题4：URL不变化

**原因：** 这是正常的，只有在Web端URL才会变化
- 移动端（Expo Go）不会显示URL
- Web端才有URL路由功能
