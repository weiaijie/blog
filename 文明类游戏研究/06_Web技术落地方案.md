# 06 Web 技术落地方案

## 推荐结论

第一版按桌面浏览器 Web Demo 来做：

| 方向 | 决策 |
| --- | --- |
| 平台 | 桌面浏览器优先，移动端第二阶段适配。 |
| 技术栈 | TypeScript + Vite + PixiJS/WebGL + React DOM UI。 |
| 地图渲染 | WebGL2 负责地图、地形、单位、资源、战争迷雾、缩放平移。 |
| 复杂 UI | React/DOM 负责城市面板、科技树、外交面板、Tooltip、百科和回合提示。 |
| WebGPU | 第一版不强依赖，只在渲染层预留后续升级接口。 |
| 存档 | IndexedDB 保存 GameState，LocalStorage 只保存轻量设置。 |
| 后台计算 | AI、寻路、地图生成、胜利评估预留 Web Worker。 |
| 部署 | 静态站点部署，能直接发链接试玩。 |

## 为什么这样选

| 选择 | 原因 |
| --- | --- |
| 不用纯 DOM 做地图 | 地图格、单位、战争迷雾、缩放和动画多了之后容易卡，也难做图层和特效。 |
| 不用纯 Canvas 2D 做全部内容 | 原型可以，但后续缩放、动画、批量渲染、图集管理会越来越吃力。 |
| 不用纯 WebGL 做全部 UI | 科技树、城市面板、外交菜单、Tooltip 用 DOM 更快、更清楚、更易维护。 |
| 不直接上 WebGPU | 兼容和技术风险更高，不利于快速验证玩法。 |
| 不优先 Unity WebGL | 包体、加载、网页 UI 结合和调试成本都更重，不适合轻量 Web 原型。 |

## 第一版架构

| 层级 | 负责内容 | 注意事项 |
| --- | --- | --- |
| GameState | 地图、城市、单位、科技、外交、胜利进度、回合数。 | 作为唯一规则数据源，方便存档、AI、回放。 |
| Simulation | 回合结算、资源增长、生产队列、科技推进、胜利检测。 | 结算顺序必须固定并可记录日志。 |
| AI Worker | AI 发展、扩张、寻路、攻击、胜利路线评估。 | 输入输出使用可序列化数据，避免传复杂对象。 |
| Render Engine | WebGL 地图、单位、资源、战争迷雾、选中高亮、路径预览。 | 只读取 GameState，不直接改规则。 |
| UI Layer | React/DOM 面板、按钮、Tooltip、百科、日志、调试面板。 | UI 操作通过命令系统提交给 Simulation。 |
| Storage | IndexedDB 存档、LocalStorage 设置。 | 存档版本号必须保留，方便后续迁移。 |
| Asset Pipeline | 地形图集、单位图集、UI 图标、音频、配置表。 | 第一版按 texture atlas 思路组织资源。 |

## 推荐开发顺序

| 阶段 | 要完成的内容 | 验收标准 |
| --- | --- | --- |
| 1. 技术骨架 | Vite + TypeScript + React + PixiJS，页面能显示 WebGL 地图。 | 能拖拽、缩放、显示 FPS。 |
| 2. 地图与输入 | 12x12 到 20x20 地图，地形、资源、选中格、单位移动。 | 点击命中准确，移动后状态正确。 |
| 3. 回合系统 | 结束回合、资源结算、城市生产、科技研究。 | 每回合日志能解释资源变化。 |
| 4. AI 与 Worker | 1 个 AI 能探索、建城、生产、移动或进攻。 | AI 思考时页面不卡。 |
| 5. 存档与读档 | IndexedDB 保存/读取一局。 | 刷新页面后能恢复同一回合状态。 |
| 6. 胜利与复盘 | 征服胜利、科技胜利、30 回合分数结算。 | 玩家能知道自己为什么赢或输。 |
| 7. 调试与试玩 | 调试地图、固定种子、FPS、AI 意图、资源日志。 | 可以稳定发链接给别人试玩。 |

## 第一版性能预算

| 指标 | 目标 |
| --- | --- |
| 桌面 FPS | 60 FPS |
| 低端设备 FPS | 至少 30 FPS |
| 地图尺寸 | 12x12 到 20x20 |
| 单位数量 | 第一版每方 10 个以内 |
| 城市数量 | 每方最多 3 座 |
| 首屏加载 | 3 秒内看到主界面或加载进度 |
| AI 思考卡顿 | 主线程不出现明显冻结 |
| 存档时间 | 本地保存/读取在可感知范围内完成 |

## 第一版必须做的调试工具

| 工具 | 用途 |
| --- | --- |
| FPS 面板 | 观察地图缩放、单位显示、战争迷雾时是否掉帧。 |
| 回合日志 | 查看资源、生产、科技、胜利检测的结算过程。 |
| AI 意图显示 | 显示 AI 当前目标，比如扩张、进攻、研究、建造。 |
| 地图坐标层 | 检查点击命中、寻路、城市范围、战争迷雾。 |
| 固定地图种子 | 复现 bug 和比较数值调整效果。 |
