# 17 浏览器兼容与技术验证清单

## 一、调研结论

第一版目标是桌面浏览器 Web Demo，兼容策略应当是：

| 层级 | 决策 |
| --- | --- |
| 主目标浏览器 | Chrome / Edge 最新稳定版 |
| 次目标浏览器 | Safari 最新稳定版、Firefox 最新稳定版 |
| 核心渲染 | WebGL2 优先，WebGL1/Canvas fallback 只作为极简兜底讨论，不作为第一版主路线 |
| WebGPU | 只做能力探测与未来预留，不作为第一版依赖 |
| 存档 | IndexedDB 必须可用；LocalStorage 只保存轻量设置 |
| 输入 | Pointer Events 统一鼠标、触控、触控笔；桌面鼠标优先 |
| Worker | Web Worker 预留 AI、寻路、地图生成；第一版可先同步实现简单 AI，但接口要可迁移 |
| OffscreenCanvas | 只做未来优化项，不进入第一版核心 |

## 二、浏览器能力矩阵

| 能力 | Chrome/Edge | Safari | Firefox | 第一版策略 |
| --- | --- | --- | --- | --- |
| WebGL2 | 目标支持 | 目标支持 | 目标支持 | 必须支持；启动时检测 `canvas.getContext("webgl2")` |
| WebGL Context Lost | 可能发生 | 可能发生 | 可能发生 | 第一版监听事件并提示刷新/恢复，第二版做完整恢复 |
| WebGPU | 支持进展较快，但仍需检测 | 支持情况需验证 | 支持情况需验证 | 不依赖；只作为长期路线 |
| Web Worker | 可用 | 可用 | 可用 | AI/寻路/地图生成预留 Worker |
| OffscreenCanvas | 支持情况需实测 | 支持情况需实测 | 支持情况需实测 | 不作为第一版核心 |
| IndexedDB | 可用 | 可用但要注意隐私模式/容量 | 可用 | 存档前做可用性检测 |
| Pointer Events | 可用 | 可用性需验证 | 可用 | 统一输入模型，保留鼠标事件兜底 |
| Fullscreen | 可用但受用户手势限制 | 限制较多 | 可用 | 第一版不强依赖全屏 |
| Audio Autoplay | 受限制 | 受限制 | 受限制 | 音频必须在用户交互后解锁 |
| Device Pixel Ratio | 高 DPR 设备常见 | 高 DPR 设备常见 | 高 DPR 设备常见 | DPR 默认封顶 2，设置中允许调整 |

## 三、启动时能力检测

| 检测项 | 失败处理 |
| --- | --- |
| WebGL2 context | 显示“当前浏览器/显卡不支持 WebGL2”，提供兼容说明 |
| IndexedDB open | 禁用存档按钮，提示“当前环境无法本地存档” |
| Worker constructor | 使用同步 AI/寻路 fallback，但 Debug 面板标记性能风险 |
| PointerEvent | 回退到 mouse/touch 事件 |
| AudioContext | 静音运行，等待首次用户点击后再次初始化 |
| localStorage | 设置不持久化，但游戏仍可运行 |

## 四、技术验证 Spike 清单

| Spike | 目标 | 验收标准 |
| --- | --- | --- |
| WebGL2 初始化 | Vite 页面创建 PixiJS/WebGL 场景 | Chrome/Edge/Safari/Firefox 均能看到地图 |
| 地图缩放平移 | 20x20 tilemap 支持拖拽和滚轮缩放 | p95 frame time 低于 33ms |
| IndexedDB 存档 | 保存并读取一局 GameState | 刷新页面后恢复同一回合 |
| Worker 通信 | 主线程发送 AI 请求，Worker 返回 Command | 超时可取消，错误可显示 |
| Pointer Events | 鼠标点击、拖拽、右键、滚轮 | 不触发页面滚动/右键菜单干扰 |
| DPR 限制 | 高分屏下 canvas 渲染尺寸封顶 | DPR=2 时仍能稳定拖拽 |
| WebGL context lost | 手动触发或模拟上下文丢失 | 显示提示，Debug 记录事件 |
| 静态部署 | Vite build 后部署到静态站点 | 资源路径、缓存、刷新都正常 |

## 六、风险清单

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| Safari 行为差异 | 存档、音频、输入、全屏可能与 Chrome 不同 | 第一版每个里程碑都做 Safari 冒烟 |
| 低端集显掉帧 | 地图拖拽缩放体验差 | DPR 封顶、culling、atlas、降低动画 |
| 隐私模式限制存储 | 存档失败 | 启动时检测 IndexedDB，可导出 Debug/Save JSON |
| WebGL context lost | 画面丢失 | 第一版提示恢复，第二版完整重建资源 |
| WebGPU 兼容不一致 | 如果早依赖会阻塞试玩 | 第一版完全不依赖 WebGPU |
| 资源缓存旧版本 | 玩家加载旧 atlas/config | HTML/manifest 短缓存，hashed assets 长缓存 |

## 七、资料来源

- MDN WebGL2RenderingContext：WebGL2 已是 widely available，并可在 Web Workers 中使用。  
  https://developer.mozilla.org/en-US/docs/Web/API/WebGL2RenderingContext

- MDN WebGPU API：WebGPU 不是 Baseline，且需要 secure context，适合作为未来预留。  
  https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API

- MDN IndexedDB API：用于 Web 端结构化数据存储。  
  https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API

- MDN Pointer Events：统一鼠标、触控、触控笔输入模型。  
  https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events

- MDN OffscreenCanvas：未来可用于离屏渲染或 Worker 渲染优化，但第一版不依赖。  
  https://developer.mozilla.org/en-US/docs/Web/API/OffscreenCanvas

- Vite Static Deploy：静态部署流程参考。  
  https://vite.dev/guide/static-deploy.html
