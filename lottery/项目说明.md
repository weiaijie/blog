# SpinLite-A40（Vue2）：低端安卓 A40 / Android 7.1.1 / 1GB 抽奖转盘方案与实现

## 0. 项目名称
**SpinLite-A40-Vue2**

目标：在 **Android 7.1.1 WebView + Quadcore-A40 + 1GB RAM** 设备上实现抽奖转盘，动画流畅、不卡顿、低内存、结果可控。

---

## 1. 关键策略（必须遵守）
1. **转盘只旋转一个元素**：`transform: rotate()`  
2. **盘面只用一张图**（推荐 WebP；不行就 PNG），不要用 DOM 扇形切片  
3. 动画期间 **每帧只改一次 transform**，不改 `top/left/width/height` 等会触发布局的属性  
4. **先拿抽奖结果，再算落点，再开转**（前端不决定中奖）  
5. 减少视觉特效：禁用 blur / 大阴影 / 大面积半透明叠加  

---

## 3. 性能验收指标（开发基准）
- 在 Chrome DevTools：**CPU 6x** + Network **Slow 3G** 下
  - 动画期间平均帧率 **>= 45fps**
  - Long Task（>50ms）尽量为 0
- JS Heap 常驻建议 **< 80MB**（峰值 < 120MB）
- 首屏可交互 **<= 2.5s**（以你业务可调）

## 4. Vue2 组件：LuckyWheel.vue（核心实现）

> 设计：  
> - `wheel` 是唯一旋转的元素  
> - 指针固定不动  
> - 用 `requestAnimationFrame` 驱动，ease-out 曲线  
> - 动画用“目标角度”落到指定奖项  
> - 结束后发出 `finish` 事件

```vue
<template>
  <div class="lw-wrap">
    <div class="lw-stage">
      <!-- 转盘：唯一旋转元素 -->
      <div
        ref="wheel"
        class="lw-wheel"
        :style="wheelStyle"
        aria-label="lucky wheel"
      ></div>

      <!-- 指针：固定不动 -->
      <div class="lw-pointer" aria-label="pointer"></div>

      <!-- 点击区域按钮（也可换成图片） -->
      <button
        class="lw-btn"
        :disabled="spinning"
        @click="onStart"
      >
        {{ spinning ? '抽奖中...' : '开始抽奖' }}
      </button>
    </div>

    <div class="lw-tip" v-if="tip">{{ tip }}</div>
  </div>
</template>

<script>
export default {
  name: "LuckyWheel",
  props: {
    // 奖项配置：每项提供 id + centerDeg（该奖项中心角度，0deg 指向顶部）
    prizes: {
      type: Array,
      required: true
      // 示例：
      // [{ id:'A', name:'一等奖', centerDeg: 0 }, { id:'B', centerDeg: 60 }, ...]
    },
    // 抽奖接口函数：必须返回 Promise<{ prizeId: string }>
    // 你可以在父组件传入：() => axios.post(...).then(res=>res.data)
    drawApi: {
      type: Function,
      required: true
    },
    // 动画时长（ms）
    duration: { type: Number, default: 5200 },
    // 最少圈数（视觉）
    minTurns: { type: Number, default: 6 },
    // 每个奖项允许的随机偏移（度数，越大越“随机”，但要保证不越界）
    // 简化处理：默认 ±6 度（适合每格 >= 30 度的情况）
    randomOffsetDeg: { type: Number, default: 6 }
  },
  data() {
    return {
      spinning: false,
      tip: "",
      // 当前累计旋转角（度）
      currentDeg: 0,
      // rAF id
      rafId: 0,
      // 动画开始时间
      startTs: 0,
      // 动画目标角
      targetDeg: 0
    };
  },
  computed: {
    wheelStyle() {
      // 只绑定 transform（不要绑定其他会触发布局的属性）
      return {
        transform: "rotate(" + this.currentDeg + "deg)"
      };
    }
  },
  beforeDestroy() {
    if (this.rafId) cancelAnimationFrame(this.rafId);
  },
  methods: {
    async onStart() {
      if (this.spinning) return;
      this.tip = "";
      this.spinning = true;

      try {
        // 1) 先拿抽奖结果（前端不决定中奖）
        const res = await this.drawApi();
        const prizeId = res && res.prizeId;

        const prize = this.prizes.find(p => p.id === prizeId);
        if (!prize) throw new Error("Unknown prizeId: " + prizeId);

        // 2) 计算最终落点角度
        // 指针固定在顶部(0deg)，当转盘旋转 θ 时，指针指向盘面角度 = (360 - (θ % 360)) % 360
        // 我们希望指向 prize.centerDeg，所以： (360 - (target % 360)) % 360 == prize.centerDeg
        // => target % 360 == (360 - prize.centerDeg) % 360
        const landing = (360 - (prize.centerDeg % 360) + 360) % 360;

        // 随机偏移：避免每次都落正中（注意别越界；这里假设每格足够大）
        const off = this.randomOffsetDeg
          ? (Math.random() * 2 - 1) * this.randomOffsetDeg
          : 0;

        // 至少转 minTurns 圈 + 落点
        const extraTurns = this.minTurns * 360;

        // 当前角度可能不是 0，要从 currentDeg 开始累加到新目标
        // 目标角 = currentDeg（起点） + extraTurns + (landing - currentDeg%360) + off
        const curMod = ((this.currentDeg % 360) + 360) % 360;
        const deltaToLanding = (landing - curMod + 360) % 360;

        this.targetDeg = this.currentDeg + extraTurns + deltaToLanding + off;

        // 3) 启动动画
        this.startTs = 0;
        this.animateToTarget(prize);
      } catch (e) {
        this.tip = "抽奖失败，请重试";
        this.spinning = false;
        this.$emit("error", e);
      }
    },

    animateToTarget(prize) {
      // 轻量 easeOutCubic：t∈[0,1] => 1-(1-t)^3
      const easeOutCubic = t => 1 - Math.pow(1 - t, 3);

      const from = this.currentDeg;
      const to = this.targetDeg;
      const dur = this.duration;

      const step = ts => {
        if (!this.startTs) this.startTs = ts;
        const elapsed = ts - this.startTs;
        const t = Math.min(1, elapsed / dur);
        const p = easeOutCubic(t);

        // 只更新 transform 相关的 currentDeg
        this.currentDeg = from + (to - from) * p;

        if (t < 1) {
          this.rafId = requestAnimationFrame(step);
        } else {
          // 结束：固定到最终角度（避免浮点误差）
          this.currentDeg = to;
          this.spinning = false;

          this.$emit("finish", {
            prizeId: prize.id,
            prizeName: prize.name,
            finalDeg: this.currentDeg
          });
        }
      };

      // 提前让 wheel 成合成层（减少抖动）
      // 注意：不要频繁切换 will-change
      if (this.$refs.wheel) {
        this.$refs.wheel.style.willChange = "transform";
        this.$refs.wheel.style.transform = "rotate(" + this.currentDeg + "deg)";
      }

      this.rafId = requestAnimationFrame(step);
    }
  }
};
</script>

6. 图片与资源建议（低端机不卡顿关键）
	1.	wheel 盘面尽量 单张图：
	•	280~360px 视觉够用（别上 1000px）
	•	WebP 优先；兼容不行就 PNG-8/PNG 压缩
	2.	指针图尽量小（< 50KB）
	3.	不要加载自定义字体（低端机容易阻塞渲染）
	4.	进入页面就预加载：
	•	new Image().src = wheelUrl; new Image().src = pointerUrl;

7. 调试方法（Chrome 开发基准）
	•	DevTools → Performance：
	•	CPU：6× slowdown
	•	录制：点击抽奖 → 观察 Main Thread 是否有长任务
	•	DevTools → Network：
	•	Slow 3G：看首屏是否拖太久
	•	重点：动画期间只应看到 “Composite Layers” 为主，不应有大量 Layout/Recalculate Style

⸻

8. 常见卡顿原因清单（排查顺序）
	1.	转盘不是单元素旋转（多个 DOM 动）
	2.	每帧做了计算/请求/日志过多（console 在低端机也卡）
	3.	盘面图太大（解码/上传 GPU 成本高）
	4.	使用了阴影/模糊/渐变叠层
	5.	动画用 setInterval 而不是 rAF（掉帧更明显）

⸻

9. 你需要补齐的两项（上线必备）
	1.	prizes.centerDeg 必须与你的盘面“奖项位置”一致
	2.	drawApi 必须由后端返回结果（prizeId/drawId/nonce）

⸻

10. 可选增强（仍然低成本）
	•	抽奖按钮点击后做 150ms 轻微缩放（只改 transform）
	•	动画结束前 300ms 加一个“咔哒”音效（注意音频预加载，避免卡顿）
	•	结果弹窗用简单层（避免复杂动画）
