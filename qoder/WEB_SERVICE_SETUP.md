# Qoder Web历史记录查看器安装与使用指南

## 概述

Qoder Web历史记录查看器是一个基于Flask的Web应用程序，用于可视化查看和搜索Qoder的历史记录、聊天会话和编辑会话。该工具提供了友好的Web界面，方便用户浏览和分析Qoder产生的各类数据。

## 系统要求

- **操作系统**: Windows 7/8/10/11, macOS, Linux
- **Python**: 3.6或更高版本
- **内存**: 至少2GB RAM（建议4GB）
- **磁盘空间**: 至少100MB可用空间

## 安装步骤

### 1. 安装Python

如果系统中没有安装Python，请按以下步骤操作：

#### Windows用户：
1. 访问 [Python官网](https://www.python.org/downloads/)
2. 下载Python 3.6或更高版本
3. 安装时勾选"Add Python to PATH"选项
4. 验证安装：打开命令提示符，输入 `python --version`

#### macOS用户：
1. 使用Homebrew安装：`brew install python3`
2. 或从官网下载安装包

#### Linux用户：
1. Ubuntu/Debian: `sudo apt-get install python3 python3-pip`
2. CentOS/RHEL: `sudo yum install python3 python3-pip`

### 2. 安装Flask

打开终端或命令提示符，运行以下命令：

```bash
pip install Flask
```

或者使用项目自带的依赖文件：

```bash
pip install -r requirements.txt
```

### 3. 启动Web服务

进入Web服务目录并启动：

```bash
cd qoder/web_service
python app.py
```

## 快速启动方式

### Windows用户

Qoder提供了多种便捷的启动方式：

1. **双击批处理文件**：
   - 双击 `start.bat` 文件即可启动服务

2. **使用PowerShell脚本**：
   - 在PowerShell中运行 `start.ps1` 脚本

3. **使用Python脚本**：
   - 运行 `start_server.py` 脚本

### 其他系统用户

```bash
cd qoder/web_service
python3 app.py
```

- 浏览会话详情

- 显示各类数据统计

## Web界面使用说明

### 页面布局

```
┌─────────────────────────────────────────┐
│              顶部导航栏                  │
├─────────────┬───────────────────────────┤
│             │                           │
│   侧边栏    │        主内容区           │
│             │                           │
│             │                           │
├─────────────┴───────────────────────────┤
│            消息发送面板                  │
└─────────────────────────────────────────┘
```

### 主要功能区域

1. **侧边导航栏**：切换不同数据类型
2. **主内容区**：显示当前选中的数据
3. **搜索框**：全局搜索功能
4. **消息面板**：发送消息（预留）

### 操作流程

1. 启动服务后，浏览器自动打开 `http://127.0.0.1:5000`
2. 选择左侧导航栏中的数据类型（聊天会话、编辑会话等）
3. 在主内容区查看数据列表
4. 点击项目查看详细内容
5. 使用顶部搜索框进行全局搜索
6. 在底部消息面板发送消息（预留功能）

## API接口说明

### GET /api/chat-sessions
获取所有聊天会话数据

### GET /api/chat-editing-sessions
获取所有编辑会话数据

### GET /api/history-files
获取历史文件列表，支持搜索参数

### GET /api/search?q={query}
在内容中搜索指定关键词

### GET /api/file-content?path={filepath}
获取指定文件的内容

### POST /api/send-message
发送消息到Qoder（预留功能）

### GET /api/stats
获取数据统计信息

## 故障排除

### 常见问题

**Q: 启动时提示找不到Python**
A: 确保Python已正确安装并添加到系统PATH

**Q: 访问页面时显示连接拒绝**
A: 检查服务是否已启动，确认端口5000未被占用

**Q: 某些功能无法正常使用**
A: 确保浏览器支持现代Web标准，清除浏览器缓存

**Q: 搜索功能没有返回结果**
A: 检查Qoder数据目录是否存在，确认数据权限

### 调试方法

1. 查看终端输出的错误信息
2. 检查浏览器开发者工具中的网络请求
3. 确认Qoder数据目录的访问权限
4. 验证Python环境配置

## 安全注意事项

- 服务仅在本地运行（127.0.0.1），不会对外暴露
- 仅限本地访问，确保数据安全
- 不传输任何数据到外部服务器
- 建议在安全的网络环境中使用
